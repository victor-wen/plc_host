# PLC 上位机设计规范

**日期:** 2026-08-06
**目标:** Windows 单 PLC Modbus TCP 上位机，核心为自由画布可编辑看板和可配置控制按钮。
**用途:** 内部自用，单机直连汇川 PLC。

## 技术基线

| 项目 | 选择 |
|---|---|
| 语言 | C++20 |
| UI | Qt 6.8 LTS Widgets |
| 看板 | Graphics View Framework (QGraphicsScene/QGraphicsView/QGraphicsObject) |
| 撤销 | QUndoStack |
| 通信 | Qt SerialBus, QModbusTcpClient |
| 趋势 | Qt Charts |
| 数据库 | Qt SQL, SQLite WAL |
| 构建 | CMake 3.24+, MSVC 2022 x64, Ninja |
| 测试 | Qt Test, CTest |
| 平台 | Windows 10/11 x64 |
| 规模 | 1 台 PLC, 最多 1000 Tag, 默认 500ms, 少量连续地址 200ms |

## 核心架构

```
UI 主线程
  主窗口, 变量表, 看板编辑器, 趋势, 报警, 配方, 日志/设置
           │
应用服务层
  采集调度, 按钮执行, 报警, 历史, 配方, CSV导出
        │                    │
Modbus 通信线程          SQLite 数据库线程
        │                    │
QModbusTcpClient       配置, 历史, 报警, 日志
        │
     汇川 PLC
```

### 线程边界

- UI 主线程只负责显示和用户操作，不直接访问 PLC 或执行数据库查询。
- 通信线程运行 QModbusTcpClient 和采集调度器。
- 数据库线程批量写入历史样本、报警事件和操作日志。
- TagCache 保存每个变量当前值、质量状态和时间戳；UI 读取缓存快照。
- UI 每 100ms 最多接收一次合并更新。

### 接口隔离

- 业务层只依赖 IModbusClient、仓储和服务接口。
- 通信实现可替换为 libmodbus 而不改界面和业务模块。

## 功能模块

### PLC 管理

- 1 台设备，配置：名称、IP、端口、Unit ID、超时、重试次数、采集周期、自动连接。
- 显示连接状态和错误信息。

### 变量管理

- 支持功能码：线圈(01)、离散输入(02)、输入寄存器(04)、保持寄存器(03)。
- 支持类型：Bool, Int16/UInt16, Int32/UInt32, Float32, 位字段。
- 字符串为低优先级扩展。
- 可配置：字节序(ABCD/DCBA/BADC/CDAB)、字序(高低/低高)、倍率、偏移、单位。
- 读写属性和采集组配置。
- 数据库保存零基 PDU 地址。界面可选零基或一基输入。

### 采集规则

- 按寄存器区、采集周期和连续地址合并读取块。
- 同一时间最多一个在途请求（兼容性优先）。
- 采集周期: 200ms/500ms/1000ms/2000ms/5000ms, 默认 500ms。
- 质量状态: Good, Stale, Bad, Disconnected。

### 实时变量表

- 表格显示当前值、工程值、原始值、质量状态、采集时间。
- 支持搜索、分组和收藏。
- 手动写入前校验类型、范围和只读属性，并要求确认。

### 自由画布看板

- 多页面看板，每页可配置名称、画布尺寸、背景色或背景图。
- 组件: 文本、矩形、图片、实时数值、数值输入、状态灯、开关、进度条、仪表、趋势小窗、可编辑按钮。
- 支持: 添加、拖动、缩放、复制、删除、网格吸附、对齐、层级调整。
- 使用 QUndoStack 支持撤销/重做。
- 显式保存、未保存标记、异常退出草稿恢复。
- 不实现任意旋转、脚本组件、复杂矢量绘图和完整 SCADA 组态编辑器。

### 编辑/运行双模式

- 编辑模式: 绝不向 PLC 写值。允许编辑布局、属性和绑定。
- 运行模式: 锁定布局，组件显示实时数据，按钮可执行 PLC 写入和页面跳转。
- 切换模式时释放所有处于按下状态的点动按钮。

### 按钮动作

- 动作类型: 点动(按下A/松开B)、切换、固定值、弹窗输入、页面跳转。
- 安全约束:
  - 只能绑定 Tag，不能直接填写裸 Modbus 地址。
  - 离线、只读、值过期或配置无效时禁用。
  - 写入前执行类型、范围和确认校验。
  - 控件显示 PLC 回读值，不乐观更新。
  - 点动默认最大保持 3 秒。超时自动发送释放值。
  - 窗口失焦、切换页面或退出运行模式时尝试释放点动。
  - 断线后清空写队列，不重放旧命令。
  - 关键运动由 PLC 看门狗/安全逻辑保护，上位机不能替代。

### 趋势

- 实时曲线和历史曲线。
- 按变量和时间范围查询。
- 缩放、游标读数。
- CSV 导出。
- 单个图表限制变量数量防止 UI 过载。

### 报警

- 触发类型: 布尔触发、高高/高/低/低低、变化报警。
- 级别、延时和回差可配置。
- 当前报警列表、历史报警查询。
- 确认和恢复记录。
- 界面颜色提示。不做声音、邮件或短信。

### 历史数据

- 变量可选择周期采样或变化采样。
- SQLite 批量写入，保留 90 天，分批自动清理。
- 时间/变量筛选查询和 CSV 导出。

### 配方

- 创建、复制、编辑、删除配方。
- 从 PLC 读取当前参数生成配方。
- 批量下发前显示差异并确认。
- 逐项校验写入结果，失败输出明细。

### 日志与设置

- 运行日志、通信错误日志、PLC 写操作记录。
- 日志按大小轮转，保留 30 天。
- 配置数据库备份/恢复，恢复前验证版本并自动备份当前。
- 无用户登录、角色或权限。

## 数据模型

```text
schema_migrations    迁移历史
plc_config           PLC 连接参数（单行）
tags                 变量定义、编解码和采集配置
dashboard_pages      看板页面（名称、尺寸、背景、排序）
dashboard_items      看板组件（位置、几何、样式JSON、配置JSON、版本号）
alarm_rules          报警规则（变量、类型、阈值、级别、延时、回差）
alarm_events         报警事件（触发、确认、恢复时间）
history_samples      历史数值和质量状态
recipes              配方元数据（名称、创建时间、变量数量）
recipe_items         配方项（tag_id, 值）
operation_logs       写入操作记录（时间、变量、旧值、新值、结果）
app_settings         应用设置键值对
```

## 异常与恢复策略

### 连接状态

```
Disconnected -> Connecting -> Online -> Degraded -> Reconnecting
```

- 重连退避: 1, 2, 4, 8, 16, 30 秒，上限 30 秒。
- 手动断开后不自动重连。
- 单次采集失败保留旧值但标记 Stale。
- 连续失败后进入 Bad/Disconnected，禁用所有写控件。

### 写入安全

- 每个写命令带唯一 ID、创建时间和有效期。
- 过期命令直接丢弃并记录日志。
- 断线时清空未执行的手动写队列。
- 重连后不重放旧按钮动作。

### 数据安全

- SQLite WAL 模式，版本化迁移，事务保护。
- 看板保存前校验页面 ID、组件几何、Tag 绑定和动作参数。
- 组件损坏时显示错误占位框，不影响其他页面。
- 数据库异常时进入只读恢复界面，不连接 PLC。

### 程序退出

- 停止新请求。
- 尝试释放仍处于按下状态的点动按钮。
- 等待有限时间。
- 提交剩余数据库批次后断开。

## 测试与验收

### 单元测试

- 地址 0/1 基转换、寄存器区映射。
- 全部 Int/UInt/Float/位字段的字节序、字序、倍率、偏移编解码。
- 连续地址合并和 Modbus 上限分组。
- 按钮点动、切换、固定值、输入、跳转状态机。
- 看板组件序列化、版本迁移、损坏隔离。
- 报警延时、回差、确认和恢复。
- 历史数据保留策略。

### 集成测试

- IModbusClient 假实现测试: 正常、超时、异常码、断线、重连。
- 本机 Modbus TCP 模拟服务器验证真实报文。
- 临时 SQLite 验证迁移、批量写入、备份和 CSV。

### 界面测试

- Qt Test 验证组件 CRUD、拖动、缩放、对齐、层级和撤销/重做。
- 看板保存/重载后位置、样式、绑定和动作一致。
- 编辑模式零写请求验证。
- 运行模式异常状态下按钮自动禁用。

### 汇川 PLC 实机验收

- 核对地址、数据类型和字节序。
- 点动按钮按下/释放、失焦、断线和超时。
- 写入应答与回读不一致时的提示。
- 1000 Tag、500ms 采集、100 个画布组件连续 8 小时无崩溃、无死锁、无误写。
- 断线后自动恢复，历史数据连续。

### 完成标准

- 全部自动化测试通过。
- 无崩溃、死锁、旧命令重放或编辑模式误写。
- 看板完整闭环。
- 备份、90天清理、历史、报警、配方、CSV 导出通过验收。
- Windows 发布包可在无 Qt 的干净机器上运行。
