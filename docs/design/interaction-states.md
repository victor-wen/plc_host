# UI-05 Luna 交互状态规范

> 本文定义 PLC Host 在看板编辑模式、看板运行模式以及跨页面操作中的视觉反馈、交互行为和状态转换，供 Qt Widgets 实现和 UI 验收使用。
> 规范基于 `design-tokens.md` 与 `information-architecture.md`；状态文字、图标和颜色必须同时表达语义，不能只依赖颜色。

## 1. 统一状态原则

### 1.1 模式边界

- **编辑模式**使用工业浅色画布，允许布局、尺寸、属性和绑定配置操作；组件预览不得触发 PLC 写请求。
- **运行模式**使用工业深色画布，布局锁定，隐藏工具箱、属性面板、网格、选中框和缩放手柄，只保留组件定义的运行交互。
- 模式切换不改变顶部工具栏、左侧导航和底部状态栏的几何位置。切换前后都必须释放点动状态，不能让延迟写命令跨越模式边界。

### 1.2 视觉和 token 约束

- 编辑器的选中边框固定为 **`#007AFF`、2px**。这是 UI-05 的组件选择色；`design-tokens.md` 中的 `accent: #0078D4` 继续用于活动导航、焦点等语义，不替代选中边框。实现层如需集中管理，应新增 `selection_border` token，而不是改变 `accent` 的含义。
- 吸附参考线固定为 `snap_guide: #00FF00`，使用虚线，仅在拖拽或对齐操作期间显示，释放后移除。
- 缩放手柄使用 `resize_handle_size: 8px`；白色填充、蓝色边框，在浅色画布上保持足够对比度。
- 常规按钮使用 `button.normal_*`、`button.hover_*`、`button.pressed_*`、`button.disabled_*` 和 `button.waiting_bg`；运行模式使用 `mode_overrides.runtime` 对应值。
- Good、Stale、Bad、Disconnected、Waiting、错误等状态都必须带文字、图标或可读提示。颜色和动画只是辅助信息。
- 动画不改变控件尺寸和布局。系统启用“减少动态效果”时，脉冲、闪烁和旋转改为静态图标或文字提示，但不能隐藏等待/错误语义。

### 1.3 状态优先级

同一控件只显示一个主状态，状态优先级如下：

1. **错误/超时反馈**：临时覆盖边框或背景，并在状态栏给出原因。
2. **Waiting**：请求已经发出，阻止重复操作。
3. **Disabled**：当前连接、质量、权限或配置不允许操作。
4. **Pressed**：用户正在按住控件或操作已进入按下保持态。
5. **Hover**：指针位于可操作区域上。
6. **Normal**：可用但没有其他瞬时交互的默认态。

错误闪烁结束后恢复到当前真实状态，不强行恢复成 Normal；例如断开连接时应回到 Disabled。

## 2. 看板编辑模式

编辑器固定为“左侧工具箱 + 中间画布 + 右侧属性面板”。画布网格和吸附步长为 10px，组件最小尺寸为 60px × 40px。

### 2.1 未选中组件

| 项目 | 规范 |
|---|---|
| 默认渲染 | 组件按配置属性正常渲染，不显示选中框、缩放手柄或运行时状态动画。实时值、仪表和趋势小窗使用占位值或快照。 |
| Hover | 指针进入组件命中区域时，在原组件外沿显示半透明边框；不改变填充、文字、尺寸或布局，不把 Hover 误认为已选中。移出后立即移除。 |
| 操作提示 | 可拖动组件显示可移动的指针语义；不可编辑区域保持默认指针。需要文字说明时使用工具提示，不在画布中添加永久标签。 |
| 点击 | 单击选中组件，进入“选中组件”态并激活属性面板；点击画布空白处清除选择。 |

Hover 边框必须明显弱于选中边框，不能使用 2px 实色蓝框，以免用户误以为属性面板已经绑定到该组件。

### 2.2 选中组件

- 组件外沿显示 **2px 实线 `#007AFF`**。边框位于组件边界外侧或不遮挡内容，不能因为选中改变组件实际尺寸。
- 显示 8 个缩放手柄：左上、上中、右上、右中、右下、下中、左下、左中。每个手柄为 **8px × 8px 白色方块**，带 `#007AFF` 边框；手柄中心对齐组件边界。
- 鼠标位于角手柄时显示双向对角缩放指针，位于边中手柄时显示对应方向缩放指针。
- 右侧属性面板激活，显示当前组件类型/名称，并可编辑位置、尺寸、外观、数据绑定和动作/高级属性。面板标题应明确显示“选中：组件名”或等价信息。
- 属性面板激活不代表组件可在编辑模式写 PLC；编辑器中的开关、按钮和输入框均为预览态。
- 键盘焦点仍使用 `border.focus`/`accent` 语义，不能以焦点环替代组件选中框。

### 2.3 多选

- 通过 Ctrl/Shift 加选或框选产生多选。**每个选中项都保留独立的 2px `#007AFF` 边框**，不以一个模糊的总框替代每个组件的边界。
- 为避免手柄重叠，多选时以主选中项（最后一个加入的项目）或选区包围盒承载一组 8 个缩放手柄；属性面板显示“已选中 N 项”，只展示可共用属性。
- 多选中的移动、对齐和删除作用于全部选中项；单个组件的独立尺寸/绑定属性只能在单选时编辑。
- 点击空白处清空全部选择；按住 Ctrl 单击已选项可移除该项。选择变化不发送 PLC 请求。

### 2.4 拖拽中

- 按住已选组件并移动后进入拖拽态；被拖拽组件（多选时为整组）临时以半透明方式渲染，建议保持内容可辨识但明显低于落位后的不透明度。
- 组件位置按 10px 网格吸附。接近其他组件边缘、中心线或网格时，在目标位置显示 **`#00FF00` 虚线吸附参考线**；水平和垂直参考线可同时出现。
- 参考线只表达几何辅助，不是组件内容、选中颜色或报警颜色；不能持久化到看板文件。
- 拖拽期间保留选中边框语义，但不重复绘制实体目标组件。状态栏或画布辅助提示可显示“移动中”，不应遮挡组件。
- 松开鼠标后写入新位置，移除半透明效果和参考线，保留选中态；按 Esc 取消本次拖拽并恢复原位置。
- 拖拽不能把组件放到超出画布有效区域的位置；被边界或最小间距限制时，应以可见的吸附结果结束，而不是生成半成品。

### 2.5 缩放中

- 从任意缩放手柄按下后进入缩放态，组件尺寸随着指针实时更新，保持当前选中边框。
- 在组件附近显示实时尺寸提示浮层，格式为 **`宽 × 高 px`**（例如 `120 × 60 px`）。浮层使用面板背景和高对比文字，跟随组件移动但不得被画布边界裁切。
- 尺寸按网格吸附，并限制在最小 60px × 40px；如组件有组件规格定义的最大尺寸，还必须遵守最大值。
- 提示浮层在每次尺寸变化时刷新，不能只在释放后显示。释放鼠标后提交尺寸并移除浮层；按 Esc 恢复缩放前尺寸。
- 缩放不会改变绑定、动作或其他属性，也不会触发 PLC 写请求。尺寸变更应进入撤销栈。

### 2.6 对齐和多选右键菜单

- 只有选中至少 2 个组件时，右键菜单显示“对齐”分组；单选或未选中时该分组隐藏或置灰并给出不可用语义。
- 菜单项固定为：
  - 左对齐
  - 右对齐
  - 上对齐
  - 下对齐
  - 水平居中
  - 垂直居中
- 菜单项按当前选区边界计算目标位置；执行后所有选中项保留独立蓝色边框，属性面板仍显示多选数量。
- 执行对齐时可短暂显示绿色虚线参考线帮助确认结果；操作完成后参考线移除，不写入画布内容。
- 对齐操作可撤销/重做，不触发 PLC 写入。右键菜单点击外部、按 Esc 或切换选择时关闭菜单。

## 3. 看板运行模式

运行模式使用深色 `runtime_canvas`，布局锁定。工具箱、属性面板、编辑网格、吸附参考线、选中框、缩放手柄和编辑工具栏全部隐藏。

### 3.1 数值组件

- 数值组件正常显示实时 Tag 值、单位和必要的质量文字/图标；不显示 Hover 边框或编辑光标。
- 数值组件不可选中、不可拖动、不可通过点击或双击触发操作。鼠标指针保持默认或只读语义。
- 数据质量为 Stale、Bad 或 Disconnected 时，保留数值上下文并同时显示对应文字/图标；不得仅用颜色变化让操作员猜测状态。

### 3.2 开关

- 开关显示明确的 `ON`/`OFF` 文字或等价可读标签，颜色只作为辅助。
- 点击可操作开关后立即进入请求中的短暂禁用/Waiting 态，防止双击或连续点击产生重复写请求；此期间保持当前值和等待提示，不接受再次点击。
- PLC 确认成功后显示新的 ON/OFF 状态并恢复可操作；请求失败时触发写入失败反馈，恢复到实际已确认值或安全的禁用态。
- 连接断开、Tag 为 Bad/Disconnected、Tag 只读或权限不足时使用 Disabled 态，显示不可用原因；不发出写请求。

### 3.3 按钮

运行按钮按照第 4 节的五态规范渲染。点击后进入 Pressed 或 Waiting 的顺序取决于动作类型，但任何正在等待应答的按钮都必须阻止重复操作，并在按钮或底部状态栏显示“等待应答”语义。

### 3.4 数值输入

- 单击只聚焦，不提交写入；**双击**后在原数值组件位置显示输入框覆盖层，覆盖层与组件边界对齐，不改变看板布局。
- 输入框获得焦点并选中当前值，保留单位、精度和范围提示；运行画布中的其他组件不因进入编辑而移动。
- 按 **Enter** 校验并确认：值合法时提交写请求并进入 Waiting；值非法时保留覆盖层，在输入框附近显示错误原因，不发送请求。
- 按 **Esc** 取消编辑，移除覆盖层并恢复原显示值，不发送写请求。
- Waiting 期间输入框不可再次提交；成功后显示确认后的值，失败时触发写入失败反馈并恢复可编辑或 Disabled（取决于连接和质量状态）。

### 3.5 趋势小窗

趋势小窗在运行模式下自动滚动：新采样点持续追加到时间轴右侧，显示窗口保持在最新时间范围，旧数据从当前视口移出。该状态只描述运行行为，不规定具体实现方式；看板布局和组件尺寸不因滚动而变化。

## 4. 按钮五种状态

以下状态适用于运行模式中的 ButtonItem，也适用于具有相同语义的连接、保存或页面操作按钮。状态变化不能造成按钮尺寸跳动。

| 状态 | 视觉 | 指针/交互 | 文字和辅助语义 |
|---|---|---|---|
| **Normal** | 使用当前模式的正常背景色和正常文字色：编辑模式为 `button.normal_bg` + `button.normal_text`，运行模式使用 runtime override。 | 可点击；无额外动画。 | 显示按钮动作文字。 |
| **Hover** | 在 Normal 基础上使用 `button.hover_bg`，表达约 10% 的背景对比加深；文字保持可读。 | `cursor = pointer`；离开命中区域后恢复 Normal。 | 不应只靠背景变化表达，可保留原动作文字。 |
| **Pressed** | 在 Hover/Normal 基础上使用 `button.pressed_bg`，背景加深约 20%，增加轻微 inner shadow；按钮内容可保持原位置。 | 表示按下或正在执行按下动作；不接受改变布局的拖拽。 | 可显示“执行中”或动作文字，不使用弹窗打断短操作。 |
| **Disabled** | 使用灰色 `button.disabled_bg`，文字使用 `button.disabled_text`；运行模式使用对应 runtime override。 | `cursor = not-allowed`；不响应点击、键盘激活或 Hover/Pressed 样式。 | 显示或通过工具提示说明禁用原因，例如“连接已断开”或“Tag 只读”。 |
| **Waiting** | 使用 `button.waiting_bg`，背景脉冲动画或在按钮内显示旋转小图标；脉冲不改变尺寸。 | 暂时不可重复点击；指针不进入 Pressed。 | 显示“等待应答…”等文字或可读的等待提示；成功/失败后离开 Waiting。 |

### 4.1 状态转换

```text
Normal ──hover──> Hover ──按下──> Pressed
  ▲                 │                │
  └────移出─────────┘                ├──请求发送──> Waiting
                                     │
                                     └──松开/完成──> Normal

任意可操作态 ──不可用条件──> Disabled
Waiting ──成功──> Normal/实际值态
Waiting ──失败或超时──> 错误反馈 ──> Normal 或 Disabled
```

- Disabled 和 Waiting 屏蔽 Hover、Pressed 和键盘重复激活。
- Waiting 的 spinner/脉冲只表示请求尚未得到结果，不表示 PLC 已经接受写入。
- 连接断开或质量变为 Bad 时，写入类按钮立即停止后续写入并转 Disabled；底部状态栏说明原因。

## 5. 点动按钮特殊行为

点动按钮（Jog/Momentary Button）不能沿用普通“点击后保持值”的语义，必须明确按住和松开边界。

1. **按下**：鼠标按下或键盘激活后立即进入 Pressed，并在按住期间保持 Pressed；不因指针在按钮内部轻微移动而回到 Hover。
2. **松开**：鼠标释放、键盘键释放或系统取消按压后结束点动，按钮恢复 Normal。释放动作必须先于页面切换和窗口关闭处理。
3. **安全超时**：从进入 Pressed 开始计时，超过 **3s** 仍未收到松开事件时，自动结束点动并恢复 Normal。
4. **超时提示**：自动恢复后，按钮边框以黄色短暂闪烁（使用 Stale/等待语义的黄色 `#C4831A`），并在底部状态栏或工具提示显示“点动已超时，已自动复位”。闪烁结束后保留普通状态，不保留 Pressed 外观。
5. **异常中断**：连接断开、Tag 质量变为 Bad、窗口失去有效控制上下文或切换到编辑模式时，立即释放点动，禁止继续写入，并显示对应错误/禁用原因。
6. 超时或异常释放后，在原按键事件彻底结束前不得再次触发一次新的点动，避免一个长按产生重复动作。

## 6. 加载和空状态

空状态必须说明上下文和下一步动作；页面标题、工具栏和筛选条件保持可见，不用空白区域代替状态提示。

| 场景 | 展示内容 | 交互行为 |
|---|---|---|
| 连接中 | 连接按钮显示 **“正在连接...”**，按钮内显示旋转动画；全局连接状态显示 `Connecting`。 | 连接按钮暂时禁用，防止重复连接；连接成功进入 Online，失败进入错误状态并恢复可重试。 |
| 无 Tag | Tag 表格内容区居中显示 **“暂无变量，点击添加”** 和“添加”按钮。 | 点击添加进入新增 Tag 流程；表头和新增入口仍可用。 |
| 看板空页 | 编辑画布中央显示 **“拖入组件开始编辑”**。 | 工具箱仍可见，支持拖拽添加或双击添加；添加首个组件后移除提示并选中新组件。 |
| 历史无数据 | 结果区域显示 **“所选时间范围无数据”**。 | 保留 Tag、时间范围、质量筛选和查询/重置按钮，允许用户调整条件后再次查询。 |
| 报警无数据 | 当前报警列表显示 **“当前无报警 ✓”**。 | 不显示空红色告警背景；刷新和切换历史报警仍可用。 |
| 配方为空 | 配方列表或内容区显示 **“点击新建创建第一个配方”**，并提供“新建配方”按钮。 | 点击按钮创建本地草稿；创建前后不改变 PLC 写入权限。 |

页面首次请求数据时，内容区可显示“正在加载”和轻量 spinner；加载态不能被误读为“无数据”。加载失败必须转入第 7 节错误态，而不是继续显示空状态。

## 7. 错误状态

### 7.1 Modbus 错误

- 底部状态栏显示红色错误提示，包含错误图标、`Modbus 错误` 标签和可读错误信息，例如“Modbus 错误：读取保持寄存器超时（地址 40001）”。
- 顶部连接状态同步显示 `Bad` 或 `Disconnected` 文字及图标；不能只把状态灯变红。
- 错误提示不覆盖 Tag 数和最后更新时间的固定位置；按信息架构约定追加在三组核心信息之后。
- 受影响的写入控件转 Disabled，已有 Waiting 请求结束并说明失败；恢复连接并收到有效数据后，状态栏回到 Online/Good 或相应质量状态。

### 7.2 写入失败

- 发起写入的按钮短暂红色闪烁，使用错误红 `state.bad`/`alarm.critical` 语义；闪烁只作为吸引注意的辅助，不替代文字。
- 建议闪烁 2 次后恢复按钮的真实状态（Normal 或 Disabled），不把失败误显示为成功或 Pressed。
- 底部状态栏追加可读错误信息，例如“写入失败：Temp_Set 无响应（超时）”；信息保留到下一次明确结果或用户关闭提示。
- 开关、数值输入和点动按钮都遵守相同反馈：恢复实际已确认值/安全状态，不能乐观地保留未确认的新值。

### 7.3 解码失败

- 发生值解码失败时，Tag 对应行或质量单元格显示红色背景（使用 Bad 语义），并显示 `Bad`/`解码失败` 文字或错误图标。
- 保留 Tag 名称、地址、原始上下文和最近一次更新时间，方便定位；不要用空白值掩盖错误。
- 解码失败的 Tag 不允许驱动写入控件进入可写状态；绑定到它的运行组件显示质量错误，而不是伪造正常值。
- 下一次成功解码后移除红色背景并恢复正常质量显示；若通信仍断开，则转为 Disconnected，而不是直接显示 Good。
