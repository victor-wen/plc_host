# UI-04 Luna 信息架构与页面线框

> 本文定义 PLC Host 的窗口骨架、导航层级、页面区域和看板编辑/运行模式。它是 UI-03 `design-tokens.md` 与 UI-01 `concepts/mixed.md` 的信息架构落地，供后续 Qt Widgets 实现使用。

## 1. 信息架构原则

1. **一个主窗口、一个工作区。** 用户始终在同一个主窗口中完成 PLC 配置、数据浏览、看板编辑和运行监控；左侧导航只切换右侧工作区内容，不打开一组互相遮挡的独立主窗口。
2. **导航表达任务，不表达实现。** 导航使用“PLC配置、Tag编辑、看板、趋势、报警、历史、配方、日志”等用户任务名称。看板的编辑和运行是同一导航项下的两种模式。
3. **编辑与运行边界清晰。** 编辑模式使用工业浅色，允许布局和配置操作但不发送 PLC 写请求；运行模式使用工业深色，隐藏编辑器工具并锁定布局，只保留运行所需的交互。
4. **状态不能只靠颜色。** Online/Disconnected、Good/Stale/Bad 等状态均同时显示指示灯、图标或文字。颜色遵循 `design-tokens.md`，不在页面中另行定义含义。
5. **稳定的空间骨架。** 模式切换只改变色彩、可见控件和交互权限，不改变顶部栏、左侧导航和底部状态栏的几何位置。

### 1.1 共用尺寸和视觉语义

- 顶部工具栏高度：44px。
- 左侧导航宽度：默认 224px，可在 196–280px 范围内调整。
- 底部状态栏高度：26px。
- 页面内普通工具栏高度：32px；面板内边距：8px；条目间距：4px。
- 看板编辑网格和吸附步长：10px；看板组件最小尺寸：60px × 40px。
- 编辑器画布使用浅色 `editor_canvas` 和网格；运行画布使用深色 `runtime_canvas`，不显示编辑网格。
- 编辑模式的活动强调色为 `#0078D4`，运行模式的活动强调色为 `#5BB9F5`；两者都只表达活动、焦点或选中。

## 2. 主窗口布局

主窗口由顶部工具栏、左侧导航、右侧工作区和底部状态栏组成。四个区域在编辑模式和运行模式中保持同一空间位置。

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [连接状态指示灯 + 设备名] [● Online / ○ Disconnected] [设置] [帮助]      │
│                                                        顶部工具栏 44px  │
├──────────────────────┬─────────────────────────────────────────────────┤
│  ◎ PLC配置            │                                                 │
│  ◇ Tag编辑            │                                                 │
│  ▦ 看板               │                         右侧工作区                │
│  ∿ 趋势               │                   根据导航切换页面内容            │
│  ! 报警               │                                                 │
│  ◷ 历史               │                                                 │
│  ▤ 配方               │                                                 │
│  ≡ 日志               │                                                 │
│      左侧导航 224px   │                                                 │
├──────────────────────┴─────────────────────────────────────────────────┤
│ 采集状态：Online / Stale / Disconnected | Tag数：248 | 最后更新时间：10:32 │
│                                                        底部状态栏 26px  │
└────────────────────────────────────────────────────────────────────────┘
```

### 2.1 顶部工具栏

顶部工具栏从左到右固定包含以下信息和操作：

1. **连接状态指示灯 + 设备名**：显示当前 PLC 的名称；有地址或站号时以较小辅助文字显示在设备名后方。
2. **连接状态**：使用明确的 `● Online` 或 `○ Disconnected` 文案。连接中、质量过期或连接异常时保留文字状态，不以单独颜色替代状态说明。
3. **当前模式标识**：看板相关页面显示“编辑模式”或“运行模式”标签；编辑模式同时提示“不会写入 PLC”，运行模式提示“布局已锁定”。非看板页面可只显示当前工作区名称。
4. **设置按钮**：进入应用、连接和显示设置；按钮命中区域保持统一，不将设置项混入左侧导航。
5. **帮助按钮**：打开快捷键、状态说明和版本信息。

顶部工具栏不承载页面表格的筛选和批量操作；这些操作放在对应页面自己的内容工具栏中，以避免切换导航后操作语义残留。

### 2.2 左侧导航

左侧导航是带图标和文字的垂直列表。每一项使用固定的图标槽位和文字槽位，避免不同文字长度造成跳动。当前页以活动背景、左侧活动标线和“当前”语义突出；不能只依赖颜色。

| 顺序 | 图标语义 | 导航文字 | 工作区职责 |
|---:|---|---|---|
| 1 | 控制器 | PLC配置 | 连接参数、采集参数和连接测试 |
| 2 | 标签/表格 | Tag编辑 | Tag 定义、绑定、质量和值浏览 |
| 3 | 网格/看板 | 看板 | 看板页面选择、编辑或运行 |
| 4 | 曲线 | 趋势 | 选择 Tag 并查看历史曲线 |
| 5 | 警铃/感叹号 | 报警 | 当前报警和历史报警 |
| 6 | 时钟/数据库 | 历史 | 查询和导出历史数据 |
| 7 | 清单/配方 | 配方 | 配方列表、配方项和操作 |
| 8 | 日志 | 日志 | 系统、通信和操作日志 |

点击导航项后，右侧工作区切换到对应页面并保留页面自己的筛选、选中行和滚动位置。看板导航项进入最近一次的看板上下文；看板内部再选择编辑模式或运行模式。

### 2.3 右侧工作区

右侧工作区占据主窗口的剩余宽度。普通页面按“页面标题/页面工具栏/内容区”组织；编辑器和监控页可以用自身的三栏或全屏画布覆盖内容区，但不覆盖顶部工具栏和底部状态栏的全局语义。

- 页面标题用于确认当前位置，例如“PLC配置”“Tag编辑”“趋势”。
- 页面工具栏只包含当前页面的新增、保存、筛选、刷新、导出或模式操作。
- 内容区优先使用平面工业面板，不通过装饰性阴影制造层级。
- 空状态直接在内容区说明下一步操作，例如“暂无变量，点击添加”或“拖入组件开始编辑”。

### 2.4 底部状态栏

底部状态栏始终显示三组最小信息：

`采集状态 | Tag数 | 最后更新时间`

- **采集状态**：显示 `Online`、`Connecting`、`Stale`、`Bad` 或 `Disconnected`，同时带指示图标。
- **Tag数**：显示当前 PLC 配置中的 Tag 数量；筛选表格时不把筛选结果误写成全局 Tag 数。
- **最后更新时间**：显示最近一批采集数据的时间；没有有效数据时显示“暂无数据”。
- 有未保存修改、写入等待、错误或日志提示时，在三组信息之后追加文字提示，不改变三组核心信息的位置。

## 4. 页面详细布局

### 4.1 PLC配置页：表单式布局

PLC配置页用于建立和检查唯一 PLC 连接。页面不使用宽表格作为主要入口，而是使用按语义分组的表单。

```text
┌─ PLC配置 ───────────────────────────────────────────────────────────────┐
│ 页面工具栏： [编辑] [测试连接]                         状态：● Online    │
├────────────────────────────────────────────────────────────────────────┤
│ 连接设置                                                               │
│ 设备名称        [ PLC-01                             ]                 │
│ 协议            [ Modbus TCP                         ]                 │
│ 主机/IP         [ 192.168.1.100                      ]                 │
│ 端口            [ 502                                ]                 │
│ 单元/站号       [ 1                                  ]                 │
│                                                                        │
│ 采集设置                                                               │
│ 采集周期        [ 500 ms                             ]                 │
│ 请求超时        [ 1000 ms                            ]                 │
│ 重试次数        [ 3                                  ]                 │
│                                                                        │
│                                      [取消] [保存配置]                 │
└────────────────────────────────────────────────────────────────────────┘
```

- 每行按“字段标签—输入控件—单位/说明”排列；标签宽度一致，输入控件左边缘对齐。
- 连接设置、采集设置和高级选项使用面板分组；错误在对应字段附近说明，不能只在底部显示一条无上下文的错误。
- 页面工具栏提供编辑、测试连接和刷新状态；保存配置位于表单底部并保持主操作位置稳定。
- 连接测试显示明确的进行中、成功或失败结果。编辑模式下保存配置只保存配置，不产生 Tag 写入请求。

### 4.2 Tag编辑页：顶部工具栏 + 全宽表格

Tag编辑页以全宽表格为核心，顶部工具栏提供表格生命周期和筛选操作。

```text
┌─ Tag编辑 ───────────────────────────────────────────────────────────────┐
│ [新增] [删除] [复制] [导入] [导出] [保存]  [搜索 Tag/地址……] [质量筛选] │
├────────────────────────────────────────────────────────────────────────┤
│ □ │启用│ Tag名称 │ 地址 │ 数据类型 │ 当前值 │ 质量 │ 读写 │ 说明       │
│ ──┼────┼─────────┼──────┼──────────┼────────┼──────┼──────┼─────────── │
│ □ │ ✓  │ Temp_01 │ 40001│ Float    │ 23.40  │ Good │ R/W  │ 入口温度    │
│ □ │ ✓  │ MotorRun│ 00001│ Bool     │ true   │ Good │ R    │ 电机运行    │
│   │    │         │      │          │        │      │      │            │
└────────────────────────────────────────────────────────────────────────┘
```

- 工具栏左侧放置新增、删除、复制、导入、导出和保存；右侧放置搜索、质量和启用状态筛选。
- 表头固定，表格占满工作区宽度；列较多时允许水平滚动，但 Tag 名称和质量状态优先保持可见。
- 每行至少包含启用状态、Tag 名称、地址、数据类型、当前值、质量、读写权限和说明。具体字段以领域模型为准，信息架构不改变领域字段命名。
- 行选择用于批量删除、复制和导出；当前质量使用左侧色条并带 `Good/Stale/Bad/Disconnected` 文字或图标。
- 没有 Tag 时表格中心显示“暂无变量，点击添加”；筛选无结果时显示“没有匹配的 Tag”和清除筛选入口。

### 4.3 看板编辑器：左侧工具箱 + 中间画布 + 右侧属性面板

看板编辑器在看板页面内部使用三栏布局，三栏的职责不能互相替代。

```text
┌─ 看板 / 编辑模式 ──────────────────────────────────────────────────────┐
│ 页面： [主画面 ▼] [新建页]   [撤销] [重做] [网格] [吸附] [缩放] [运行] │
├──────────────┬─────────────────────────────────────┬───────────────────┤
│ 组件工具箱   │              编辑画布                 │ 属性面板          │
│ 显示类       │  · 10px 网格                           │ 选中：ValueItem   │
│ 控制类       │  · 可滚动、可缩放                       │ 位置与尺寸        │
│ 图表类       │  · 组件选中框与缩放手柄                 │ 外观              │
│ 装饰类       │                                         │ 数据绑定          │
│              │                                         │ 动作/高级          │
└──────────────┴─────────────────────────────────────┴───────────────────┘
```

- **左侧工具箱**：按类别列出可添加组件，详见第 5 节。
- **中间画布**：编辑画布使用浅色背景和 10px 网格，可滚动、缩放和吸附；组件按网格放置。
- **右侧属性面板**：显示当前选中组件的几何、外观、数据绑定和动作属性；多选时显示选中数量以及可共用的属性。
- 顶部编辑工具栏提供撤销、重做、保存、网格、吸附、缩放、对齐和进入运行模式；保存按钮在有未保存修改时使用文字提示。
- 空画布中心显示“拖入组件开始编辑”。编辑器中的数值、仪表和趋势只显示占位值或快照预览；开关、按钮和输入框不触发 PLC 写入。

### 4.4 看板运行：全屏画布 + 顶部页面标签栏 + 底部状态信息

看板运行模式是面向操作员的监控画面。右侧工作区内画布最大化显示，编辑器工具箱、属性面板、网格、选中框和缩放手柄全部隐藏。

```text
┌─ 看板 / 运行模式 ──────────────────────────────────────────────────────┐
│ [主画面] [工艺总览] [设备状态]                         [返回编辑]      │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│                         深色全屏运行画布                               │
│                实时数值、状态、控制和趋势组件                           │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│ ● Online | 当前页：主画面 | Tag质量：Good 248 | 最后更新：10:32:18      │
└────────────────────────────────────────────────────────────────────────┘
```

- 顶部页面标签栏显示当前看板的页面标签；当前页使用活动态，标签顺序和页面名称与编辑器一致。
- 运行画布使用 `runtime_canvas` 深色背景，组件保持编辑时的几何位置；不显示工具箱、属性面板、编辑网格、选中态或手柄。
- 只有组件定义的运行交互可用：开关、按钮和数值输入遵循各自的写入确认与等待状态；静态显示组件不可被选中。
- 底部状态信息保留采集状态、当前页、质量摘要和最后更新时间；写入等待、失败和超时使用文字提示。
- “返回编辑”是明确的模式切换入口，不通过点击画布空白处退出运行。

### 4.5 趋势页：左侧 Tag选择面板 + 右侧图表区 + 底部时间控件

```text
┌─ 趋势 ──────────────────────────────────────────────────────────────────┐
│ [刷新] [暂停滚动]                                      数据状态：Good  │
├──────────────────────┬─────────────────────────────────────────────────┤
│ Tag选择              │ 图表区                                          │
│ [搜索 Tag……]         │  图例：Temp_01  MotorSpeed                     │
│ □ Temp_01  ● Good    │                                                 │
│ □ MotorSpeed ● Good  │        曲线、坐标轴、网格、游标和时间刻度         │
│ □ Pressure  ! Stale  │                                                 │
│ [全选] [清空]         │                                                 │
├──────────────────────┴─────────────────────────────────────────────────┤
│ 时间范围：[15分钟] [1小时] [8小时] [24小时] [自定义]  [应用] [导出]     │
└────────────────────────────────────────────────────────────────────────┘
```

- 左侧 Tag 选择面板支持搜索、分组、复选和清空；每个 Tag 显示质量文字/图标，选中后在图表中获得稳定的曲线颜色。
- 右侧图表区负责图例、坐标轴、网格、曲线、游标和无数据提示；多条曲线的单位不一致时在图例和轴标签中明确说明。
- 底部时间控件集中管理预设时间范围、自定义开始/结束时间、应用、暂停/继续和导出。时间筛选不放入左侧 Tag 列表，避免混淆筛选对象。
- 运行监控上下文使用深色图表容器；普通查询沿用编辑模式浅色面板，但信息层级和操作位置不变。

### 4.6 报警页：当前报警/历史报警两个标签页 + 表格

```text
┌─ 报警 ──────────────────────────────────────────────────────────────────┐
│ [当前报警] [历史报警]                         [确认选中] [刷新] [筛选]  │
├────────────────────────────────────────────────────────────────────────┤
│ 严重度 │ 状态 │ 发生时间 │ 恢复/确认时间 │ Tag/报警名 │ 消息 │ 当前值   │
│ ───────┼──────┼──────────┼───────────────┼────────────┼──────┼──────── │
│ ! Critical│未确认│10:31:04│ —             │Temp_High   │入口温度高│ 86.2  │
│ △ Warning │已确认│10:20:18│10:24:02       │Level_Low   │液位偏低  │ 18%   │
└────────────────────────────────────────────────────────────────────────┘
```

- **当前报警**显示未恢复和待处理事件，默认按严重度和最新发生时间排序；提供确认选中或确认全部操作。
- **历史报警**显示已恢复或已确认事件，支持时间、严重度、Tag 和状态筛选。
- 表格使用左侧严重度色条、图标和 `Critical/Warning/Info` 文字；确认后去除强背景但保留严重度语义。
- 当前无报警时显示“当前无报警”；历史无结果时显示“所选条件无报警记录”。

### 4.7 历史数据页：顶部筛选条件 + 表格 + 导出按钮

```text
┌─ 历史数据 ──────────────────────────────────────────────────────────────┐
│ Tag：[选择 Tag]  时间：[开始] 至 [结束]  质量：[全部]  [查询] [重置]   │
│                                               [导出 CSV] [导出数据]     │
├────────────────────────────────────────────────────────────────────────┤
│ 时间戳              │ Tag名称    │ 数值    │ 单位 │ 质量 │ 来源/状态    │
│ 2026-08-06 10:31:00 │ Temp_01    │ 23.40   │ °C   │ Good │ 采集          │
│ 2026-08-06 10:30:30 │ Temp_01    │ 23.35   │ °C   │ Good │ 采集          │
└────────────────────────────────────────────────────────────────────────┘
```

- 顶部筛选区按“Tag、时间范围、质量”组织，查询和重置操作放在筛选条件末端。
- 导出按钮固定在筛选区右侧，导出内容遵循当前筛选条件，并在操作后给出成功、失败或无数据提示。
- 表格以时间戳为主排序，显示 Tag、数值、单位、质量和来源/状态；质量同时使用状态文字或图标。
- 查询无数据时显示“所选时间范围无数据”，不以空白表格代替说明。

### 4.8 配方页：左侧配方列表 + 右侧配方项表格 + 底部操作按钮

```text

│   产品 C              │ Speed_Set  │ 1200   │ rpm  │ 0    │ 3000 │ 有效 │
│ [新建配方]            │                                                 │
├──────────────────────┴─────────────────────────────────────────────────┤
│ [新建项] [删除项] [复制配方] [保存] [应用到PLC] [删除配方]              │
└────────────────────────────────────────────────────────────────────────┘
```

- 左侧列表用于搜索、选择、新建和删除配方；当前配方高亮，列表项可显示草稿或已保存状态。
- 右侧配方项表格用于编辑 Tag/参数名、目标值、单位、上下限和有效性；数值校验在单元格附近说明。
- 底部操作按钮保持固定：保存只保存本地配方；“应用到PLC”是单独的写入动作，连接断开、质量为 Bad 或正在等待应答时禁用，并需要确认。
- 配方为空时显示“点击新建创建第一个配方”；没有配方项时在右侧显示“点击新建项添加参数”。

### 4.9 日志页

日志页沿用“顶部筛选工具栏 + 全宽日志表格”的结构，方便与 Tag 编辑和历史数据页保持一致。工具栏提供级别、来源、时间范围和关键词筛选；表格显示时间、级别、来源、消息和关联对象。日志内容为只读，空结果显示“没有匹配的日志”。

## 5. 看板工具箱

工具箱位于看板编辑器左侧，以可折叠分类呈现。每个组件条目包含图标、名称和简短说明；列表顺序固定，便于键盘和鼠标定位。

### 5.1 分类和组件

```text
显示类
  文本 / 图片 / 数值 / LED / 进度条 / 仪表

控制类
  开关 / 按钮 / 输入框

图表类
  趋势小窗

装饰类
  矩形
```

工具箱分类必须保持为：**显示类(文本/图片/数值/LED/进度条/仪表) | 控制类(开关/按钮/输入框) | 图表类(趋势小窗) | 装饰类(矩形)**。

### 5.2 添加方式

- **拖拽添加**：从工具箱拖动组件到画布，在释放位置按 10px 网格吸附并创建组件；画布显示绿色参考线时表示对齐辅助，不把绿色作为选中颜色。
- **双击添加**：双击工具箱条目，在画布可视区域中央或当前视口中心创建一个默认尺寸组件，并立即选中它。
- 添加完成后，属性面板自动切换到新组件；用户可以修改位置、尺寸、样式和绑定。
- 组件放置失败时保留工具箱选择，不创建半成品；画布没有可用空间时给出文字提示。
- 编辑模式中控制类组件只作为布局预览，不会因为拖拽、双击或点击预览而发送 PLC 写请求。

## 6. 画布操作和模式边界

### 6.1 编辑模式

编辑模式的固定结构为：**左侧工具箱 + 中间画布(带网格) + 右侧属性面板**。

- 画布支持单选、多选、拖动、缩放、对齐、网格显示/隐藏、吸附开关和缩放比例调整。
- 选中组件使用蓝色轮廓和 8 个缩放手柄；多选时每个组件保留独立轮廓，属性面板显示选中数量。
- 拖动和对齐时显示绿色吸附参考线，释放鼠标后移除；参考线不作为持久化画布内容。
- 画布顶部工具栏提供撤销、重做、保存、网格、吸附、缩放和对齐；未保存状态使用“未保存”文字和 Stale/等待语义，不与 PLC Bad 红色混淆。
- 编辑器只进行本地布局和配置编辑。实时值、仪表、趋势小窗使用占位或快照；按钮、开关、输入框不可执行写入。

### 6.2 运行模式

运行模式的固定结构为：**全屏画布(无工具箱/属性面板) + 顶部页面标签 + 底部状态信息**。

- 隐藏工具箱、属性面板、网格、参考线、选中框、缩放手柄和编辑工具栏。
- 画布使用深色运行背景；布局锁定，实时数据变化不得改变组件几何位置。
- 顶部页面标签用于切换看板页；底部状态信息显示采集状态、质量摘要、当前页和最后更新时间。
- 数值、LED、进度条、仪表和趋势小窗只负责运行时显示；开关、按钮和输入框才显示运行交互态。
- 写入类控件在 `Bad` 或 `Disconnected` 时同时显示不可用文字并禁用，不能只降低颜色。

### 6.3 切换模式确认对话框

编辑模式和运行模式之间的切换必须经过明确的确认对话框；对话框标题和主按钮都写出目标模式，不能使用含义不清的“确定”。

**编辑模式 → 运行模式：**

- 有未保存修改时显示：`看板存在未保存修改。进入运行模式前要如何处理？`
- 提供三个选项：`保存并进入运行模式`、`不保存直接进入`、`取消`。
- 对话框说明：进入运行模式后布局锁定，控制类组件可能发送 PLC 写请求；进入前释放所有点动状态并阻止延迟写命令跨越模式边界。
- 没有未保存修改时仍显示简短确认：`进入运行模式？布局将锁定。`，主操作为`进入运行模式`，次操作为`取消`。

**运行模式 → 编辑模式：**

- 显示：`退出运行模式并返回编辑器？当前控制操作将停止。`
- 提供`返回编辑模式`和`取消`；返回前释放点动按钮、结束等待中的交互提示，并保持当前页面标签。
- 切换完成后恢复浅色编辑画布、工具箱、属性面板和网格，但不恢复任何运行模式的选中状态。

对话框中的模式名称、未保存状态和写入风险必须同时以文字表达；颜色、图标或动画只能作为辅助。

## 7. 跨页面状态和空状态

- 顶部连接状态和底部采集状态在所有页面同步显示，不因切换导航而重置。
- 页面正在加载时保留页面标题和骨架区域，并在内容区显示“正在加载”；不能用空白页面让用户误判为无数据。
- 无数据、无筛选结果、连接断开和权限不足分别给出原因及下一步操作。
- 当前导航项、当前看板页、趋势选中的 Tag 和各表格筛选条件属于各自页面状态；切换页面后可恢复，不覆盖全局连接状态。
- 视觉模式使用 UI-01/UI-03 的混合方案：编辑页面和看板编辑器使用工业浅色，运行看板使用工业深色；共享布局尺寸、字体和状态语义不变。
