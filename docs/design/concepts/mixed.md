# UI-01 视觉方向提案：深浅混合方案

## 1. 设计定位

深浅混合方案把**编辑器的高精度操作**和**运行画面的长期监控**视为两种不同的视觉任务：编辑模式使用工业浅色界面，网格、选中框、参考线和属性表单有最高可读性；运行模式切换到工业深色画面，减少大面积白色对长时间值守的刺激，并让异常状态色在暗底上保持醒目。

这是有意的模式分界，不是单个页面随意混色。模式切换必须同时改变画布、工作区工具栏和模式标签，保持布局几何不变，避免用户误以为仍在编辑或误触写入。

本方案仍遵循扁平、可靠的工业控制风格：无渐变、无玻璃效果、无装饰性阴影和霓虹发光；只在模式切换时改变颜色语义和可见控件。

### 1.1 字体、密度和共用尺寸

- 字体统一使用 **Segoe UI**：标题 18px，页面标题 14px，正文 12px，辅助信息 10px，看板数值 20px，仪表标签 11px。
- 32px 是常规控件高度，主要按钮最小 36px，导航项 36px，组件最小命中区域 28px；所有尺寸是 Qt 逻辑像素。
- Qt 布局负责 100%/125%/150%/200% Windows DPI 缩放；不可在编辑和运行两套主题中使用不同的物理尺寸。
- 共享结构的圆角为按钮 4px、面板 6px、看板项 4px；不通过圆角或阴影暗示可写入能力。

## 2. 双模式色板

### 2.1 编辑模式：工业浅色

| 角色 | HEX | 用途 |
|---|---|---|
| 主色 | `#1F5A94` | 活动导航、主操作、模式标签 |
| 背景 | `#F2F5F7` | 浅色应用外框和工作区 |
| 面板 | `#FFFFFF` | 工具箱、属性、表格和工具栏 |
| 文字 | `#17212B` | 标题、正文、Tag 和数值 |
| 边框 | `#C5CFD8` | 面板、输入框和表格边界 |
| 强调色 | `#0078D4` | 选中框、焦点框、链接 |
| 编辑网格 | `#E2EAF0` / `#C9D7E1` | 细网格 / 主网格 |

### 2.2 运行模式：工业深色

| 角色 | HEX | 用途 |
|---|---|---|
| 主色 | `#2E77A8` | 运行工具栏、页面标签、可操作按钮 |
| 背景 | `#111820` | 运行画布和运行工作区 |
| 面板 | `#1B242D` | 页面标签栏、状态栏、趋势/报警容器 |
| 文字 | `#F1F5F8` | 标题、正文、Tag 和数值 |
| 边框 | `#3A4854` | 面板、表格和输入框边界 |
| 强调色 | `#5BB9F5` | 当前页面、焦点和交互反馈 |
| 运行画布 | `#111820` | 默认纯色背景；页面可配置其他深色 |

### 2.3 共享语义色

| 语义 | 编辑模式信号/底色 | 运行模式信号/底色 | 形状和文字 |
|---|---|---|---|
| Good | `#1B8E53` / `#E6F4EC` | `#32C36C` / `#193B2A` | 实心圆点 + Good/正常 |
| Stale | `#C4831A` / `#FFF4D9` | `#E5A83B` / `#42351E` | 三角叹号 + Stale/过期 |
| Bad | `#C73E3E` / `#FBE8E8` | `#F05D5E` / `#452326` | 叉号/八边形 + Bad/错误 |
| Disconnected | `#6B7280` / `#EEF0F2` | `#7F8B96` / `#2A3239` | 断开图标 + Disconnected/未连接 |

同一质量状态在两种主题中可以使用不同明度，但不能改变语义。每个状态都必须有文字或图标；颜色不是唯一信息源。

## 3. 主窗口布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ ● 在线  PLC-01 / 192.168.1.100   [编辑模式] [保存] [设置] [?]     │  顶部状态栏 44px
├──────────────┬─────────────────────────────────────────────────────┤
│ PLC 配置     │                                                     │
│ Tag 编辑     │                    右侧工作区                       │
│ 看板         │             当前页面内容/编辑器/运行画面             │
│ 趋势         │                                                     │
│ 报警         │                                                     │
│ 历史         │                                                     │
│ 配方         │                                                     │
│ 日志         │                                                     │
├──────────────┴─────────────────────────────────────────────────────┤
│ 采集：500 ms  |  Tag：248  |  最近更新：10:32:18  |  无未保存修改   │  底部状态栏 26px
└────────────────────────────────────────────────────────────────────┘
```

### 3.1 不变的空间骨架

- 顶部状态栏 44px、底部状态栏 26px、左侧导航约 224px（196–280px 可调）在两种模式保持同一几何位置。这样切换主题不会导致组件跳动，也不会让操作者误认为页面发生了重排。
- 左侧导航始终包含：**PLC 配置、Tag 编辑、看板、趋势、报警、历史、配方、日志**。编辑模式使用 `#EAF0F4` 浅色导航底，运行模式使用 `#151E26` 深色导航底；活动标线分别为 `#0078D4` 和 `#5BB9F5`。
- 顶部左侧始终显示连接状态、设备名称和地址；顶部中部显示清晰的“编辑模式/运行模式”标签；右侧保留设置、帮助和退出运行的入口。
- 底部始终显示采集周期、Tag 数、最近更新和错误/写入反馈；编辑模式额外显示未保存标志，运行模式显示运行时质量摘要。
- 颜色变化必须伴随模式文字变化：浅色编辑器看到“编辑模式 / 不会写入 PLC”，深色运行画面看到“运行模式 / 布局已锁定”。

### 3.2 分辨率和 DPI

| 环境 | 处理方式 |
|---|---|
| 1366×768 | 导航 224px；编辑器的工具箱和属性面板可折叠，运行画面优先保证组件和底部质量状态可见 |
| 1920×1080 | 默认骨架；编辑器工具箱约 224px、属性面板约 288px；运行画面使用深色全宽工作区 |
| 2560×1440 | 可增加工作区留白和趋势显示宽度；导航最多 248px，不能用巨大标题填充空白 |
| 100%/125%/150%/200% DPI | 两种模式共用 Qt 布局、逻辑像素和字体度量；检查切换前后控件边界、命中区、图标和文字对齐 |

## 4. 看板编辑模式：浅色高对比度

### 4.1 编辑器内部布局

```text
┌────────────┬─────────────────────────────────────┬───────────────┐
│ 组件工具箱 │          浅色网格画布                │  属性面板      │
│ 显示类     │   高对比度、可滚动、可缩放           │  位置/尺寸      │
│ 控制类     │                                     │  样式/绑定      │
│ 图表类     │                                     │  动作/高级      │
└────────────┴─────────────────────────────────────┴───────────────┘
```

- 工具箱和属性面板使用白色 `#FFFFFF`，外框 `#C5CFD8`；工作区外框 `#F2F5F7`。
- 画布底色 `#F8FAFC`，10×10px 逻辑网格，细线 `#E2EAF0`、每五格主线 `#C9D7E1`；缩放低于 50% 隐藏细线。
- 单选组件绘制 `#0078D4` 蓝色边框和 8 个 8×8px 手柄；多选保持每项独立边框，并在属性面板显示数量。
- 拖动/对齐的参考线使用 `#1B9A62` 绿色，释放鼠标后移除；蓝色仅表示选中/焦点，绿色仅表示几何辅助。
- 编辑模式工具栏提供撤销/重做、保存、网格/吸附开关、缩放和对齐命令。网格关闭时仍保留 10px 吸附设置状态的文字提示，避免“看不见网格就不知道是否吸附”。

### 4.2 编辑安全边界

- 看板编辑器中不显示 PLC 实时写入结果；Value、Gauge、Trend 使用占位或快照预览，Button/Switch 不可触发写操作。
- 页面存在未保存修改时，顶部保存按钮和底部未保存标志使用 `#C4831A` 提醒；不使用红色，避免与 PLC 故障混淆。
- 切换到运行模式前提示保存/继续，并释放所有点动按钮；切换过程中不允许后台延迟写命令穿过模式边界。

## 5. 看板运行模式：深色低疲劳

- 运行工作区、看板画布和运行工具栏切换到深色：画布 `#111820`，面板 `#1B242D`，提升层 `#222E38`，文字 `#F1F5F8`，边框 `#3A4854`。
- 纯色背景默认 `#111820`，页面可以指定其他纯色。隐藏网格、吸附线、选中框、8 个手柄、工具箱、属性面板和编辑工具栏。
- 运行模式只保留页面标签、连接状态、停止/返回、必要的页面导航和底部状态；布局锁定，组件不会因监控数据变化而改变几何。
- 运行画面没有“选中”状态。组件自身用于业务表达的边框可以存在，但不能采用与 `#5BB9F5` 选中框相同的虚线/手柄样式。
- 运行画面长时间值守时，Trend 使用深色绘图区，报警使用有限的色条和图标；红/黄状态不通过全屏闪烁呈现。

## 6. 按钮五种状态

按钮主题跟随当前模式：编辑模式中的按钮只出现在工具栏/属性面板，运行模式的动作按钮使用深色状态。五种语义保持一致。

| 状态 | 编辑模式（浅色） | 运行模式（深色） | 说明 |
|---|---|---|---|
| Normal 正常 | 背景 `#1F5A94`、白字 | 背景 `#2E77A8`、白字 | 可执行，显示动作文字 |
| Hover 悬停 | `#174A7A`、白字 | `#3E8FC4`、白字 | 仅可用控件，鼠标手型 |
| Pressed 按下 | `#103551`、白字 | `#1F587C`、白字 | 轻微内边；点动保持期间持续 |
| Disabled 禁用 | `#DEE4E8`、`#8A96A1` | `#303B45`、`#788691` | 断线、只读、Bad/Disconnected 或配置无效 |
| Waiting 等待应答 | `#C4831A`、白字 | `#C98A24`、`#111820` | 3px 状态条 + 12px spinner，禁止重复触发 |

- Waiting 只在收到 PLC 回读、错误或超时后退出；点动超过 3 秒自动释放并在底部提示。
- 颜色变化不替代文字变化：可以在按钮下方显示“等待 PLC 应答”，错误时显示具体原因。
- Hover/Pressed 不用渐变或发光；禁用态必须同时降低饱和度和交互反馈。

## 7. 质量状态与连接状态

### 7.1 统一表现

- 顶部状态永远显示 8px 圆点 + 文字；Good/Online 稳定绿色，Stale/Degraded/Connecting 使用黄橙色，Bad 使用红色，Disconnected 使用灰色。
- Stale 保留最近有效值和时间，不能显示为 0；Bad/Disconnected 的写入型按钮直接禁用。
- 表格以左侧 4px 色条表达质量，数值旁显示质量文字或 tooltip；看板组件在空间不足时至少保留状态图标。

### 7.2 主题对应色

| 质量 | 编辑模式信号/底色 | 运行模式信号/底色 |
|---|---|---|
| Good | `#1B8E53` / `#E6F4EC` | `#32C36C` / `#193B2A` |
| Stale | `#C4831A` / `#FFF4D9` | `#E5A83B` / `#42351E` |
| Bad | `#C73E3E` / `#FBE8E8` | `#F05D5E` / `#452326` |
| Disconnected | `#6B7280` / `#EEF0F2` | `#7F8B96` / `#2A3239` |

## 8. 趋势与报警页面

### 8.1 趋势

- 进入看板运行或运行监控时，趋势容器使用深色：容器 `#1B242D`、绘图区 `#151E26`、网格 `#35434E`、坐标文字 `#B4C0CA`。
- 编辑/配置趋势参数时，预览容器使用浅色：容器 `#FFFFFF`、绘图区 `#F8FAFC`、网格 `#DCE5EB`、坐标文字 `#526170`。
- 曲线语义色保持相同顺序但调整明度：编辑蓝 `#0078D4` / 运行蓝 `#5BB9F5`；编辑青绿 `#168A91` / 运行青绿 `#45C3B0`；编辑橙 `#C4831A` / 运行橙 `#E0A63F`。
- Stale 曲线段使用同色虚线或透明度，Bad/Disconnected 使用断点和图例文字。

### 8.2 报警

- 编辑/查询表格使用浅色面板，Critical `#C73E3E` + `#FBE8E8`、Warning `#C4831A` + `#FFF4D9`、Info `#2B6CB0` + `#E8F1FA`。
- 运行监控使用深色面板，Critical `#F05D5E` + `#452326`、Warning `#E5A83B` + `#42351E`、Info `#5BB9F5` + `#1C3445`。
- 两种模式都使用左侧色条、铃铛/三角/信息图标和文字；确认后去掉浅色底但保留严重度色条，恢复事件使用绿色勾号。

## 9. 模式切换验收清单

在 1366x768、1920x1080、2560x1440 和 100%/125%/150%/200% DPI 下确认：

1. 切换前后顶部、导航、底部状态栏的几何位置不跳动。
2. 浅色编辑器有清晰网格、蓝色选中框、8 个手柄和绿色参考线；深色运行画面没有这些编辑装饰。
3. 模式标签、工具箱/属性面板可见性、写入能力和按钮状态一致；不会仅凭颜色猜测当前模式。
4. 运行画面长期显示时正文、数值、趋势和报警可读，状态色不会大面积闪烁。
5. 高 DPI 下没有文字裁切、图标模糊、按钮命中区缩小或两套主题尺寸不一致。
