# UI-01 视觉方向提案：工业浅色方案

## 1. 设计定位

工业浅色方案以“看得清、改得准、状态不误判”为第一目标。它适合以编辑、配置和调试为主的工作方式：白色面板提供清晰层级，冷灰背景降低大面积纯白带来的刺眼感，蓝色作为唯一主交互色，状态色只用于表达设备质量、报警和执行结果。

本方案不使用渐变、玻璃效果、装饰性插画或大面积阴影。所有颜色均为扁平填充，圆角控制在 6px 以内，保证 Qt Widgets 在不同 DPI 下仍然像工业工具而不是通用后台模板。

### 1.1 字体与密度

- 字体统一使用 **Segoe UI**；数值、时间和地址使用等宽数字特性（若平台字体回退，则保持 Segoe UI，不强制引入额外字体）。
- 标题 18px，页面标题 14px，正文 12px，辅助信息 10px，看板数值 20px，仪表标签 11px。
- 这些尺寸均为 Qt 的逻辑像素，不按物理屏幕像素重复放大；由 Qt 高 DPI 支持处理 100%/125%/150%/200% Windows DPI。
- 默认控件高度 32px，主要按钮最小高度 36px，导航项高度 36px；鼠标命中区域不得低于 28px。
- 边框 1px，获得焦点时使用 2px 蓝色外框；不以粗边框代替状态文字。

## 2. 主色板

| 角色 | HEX | 用途 |
|---|---|---|
| 主色 `primary` | `#1F5A94` | 主窗口标题、活动导航、主操作按钮、连接信息中的品牌色 |
| 主色悬停 | `#174A7A` | 主按钮和导航项悬停 |
| 背景 `background` | `#F2F5F7` | 主窗口、页面外框、空白工作区 |
| 面板 `panel` | `#FFFFFF` | 侧栏、工具箱、属性面板、表格和卡片 |
| 面板次级 | `#EAF0F4` | 工具栏分组、表头、选中行的低强度底色 |
| 文字 `text-primary` | `#17212B` | 标题、正文、Tag 名称、数值 |
| 文字次级 | `#526170` | 单位、时间、说明和次要操作 |
| 文字禁用 | `#8A96A1` | 禁用控件和不可用说明 |
| 边框 `border` | `#C5CFD8` | 面板分隔、表格网格、输入框边框 |
| 边框悬停 | `#8EA4B7` | 可交互区域悬停 |
| 强调 `accent` | `#0078D4` | 选中框、焦点框、吸附辅助状态、链接和键盘焦点 |
| 编辑参考线 | `#1B9A62` | 拖拽/对齐吸附线，避免与蓝色选中框混淆 |

### 2.1 颜色使用规则

- 主色用于“操作入口”和“当前所在位置”，强调色用于“当前选中/当前焦点”；两者不在同一控件上叠加成渐变。
- 正文文字在白色面板上使用 `#17212B`，次级文字使用 `#526170`。禁用文字只能和禁用底色成对使用。
- 主色按钮使用白色文字；普通正文不使用纯黑 `#000000`，避免在长时间操作时形成过硬对比。
- 状态不能只由颜色表达：所有状态同时显示圆点/图标、文字标签或 tooltip；色盲用户仍可通过文字识别。

## 3. 主窗口布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ ● 在线  PLC-01 / 192.168.1.100   [编辑模式] [保存] [设置] [?]     │  顶部状态栏 44px
├──────────────┬─────────────────────────────────────────────────────┤
│ PLC 配置     │                                                     │
│ Tag 编辑     │                    右侧工作区                       │
│ 看板         │             当前页面内容/编辑器/运行画面             │
│ 趋势         │                                                     │
│ 报警         │                                                     │
│ 历史         │                                                     │
│ 配方         │                                                     │
│ 日志         │                                                     │
├──────────────┴─────────────────────────────────────────────────────┤
│ 采集：500 ms  |  Tag：248  |  最近更新：10:32:18  |  无未保存修改   │  底部状态栏 26px
└────────────────────────────────────────────────────────────────────┘
```

### 3.1 外框分区

1. **顶部状态栏/工具栏**：高度 44px，背景使用 `#FFFFFF`，底部 1px `#C5CFD8`。左侧依次显示质量圆点、连接状态文字、设备名称和地址；中部显示当前页面/模式；右侧显示保存、设置和帮助。连接状态永远比装饰性标题优先。
2. **左侧导航树**：宽度 224px（允许在 196–280px 之间调整），背景使用 `#EAF0F4`，右边 1px `#C5CFD8`。导航项包含图标、中文名称和可选计数；活动项使用 `#DCECF9` 底色、左侧 3px `#0078D4` 标线和 `#174A7A` 文字。
3. **右侧工作区**：占用剩余空间，外层背景 `#F2F5F7`。页面标题、上下文工具栏和内容面板均在此区域内，不把页面内容铺到导航上。
4. **底部状态栏**：高度 26px，背景 `#EAF0F4`，文字 10px `#526170`。左侧报告采集/连接，右侧报告 Tag 数、最近更新、未保存标志和当前缩放比例。异常信息保留直到下一次成功更新或用户关闭。

### 3.2 导航与工作区行为

- 导航顺序固定为：**PLC 配置、Tag 编辑、看板、趋势、报警、历史、配方、日志**。
- 活动导航项只使用一个蓝色标线，不同时使用粗体、阴影、渐变和大色块。
- 右侧工作区的页面标题距离边缘 16px，面板之间 8px；表格、图表和看板均遵循相同的标题/内容层级。
- 1366x768 下不压缩字体：导航保持 224px，工作区通过滚动和折叠属性面板释放空间；1920x1080 使用默认尺寸；2560x1440 可将导航增至 240px、属性面板增至 288px，但不拉伸单个控件到难以扫描的宽度。
- 100%/125%/150%/200% DPI 下使用 Qt 的逻辑尺寸和布局管理器，不以硬编码物理坐标定位控件。面板宽度、文字和命中区域随系统比例整体缩放。

## 4. 看板编辑模式

编辑模式必须让用户明确知道“现在只能改布局和属性，不能向 PLC 写值”。顶部模式控件使用浅蓝底的分段开关，选中 `编辑模式` 后显示铅笔图标和“不会写入 PLC”的辅助提示；所有写入型组件在编辑器中只显示占位值或静态预览。

### 4.1 编辑器内部布局

```text
┌────────────┬─────────────────────────────────────┬───────────────┐
│ 组件工具箱 │             网格画布                 │  属性面板      │
│ 显示类     │   可滚动、可缩放、自由摆放组件       │  位置/尺寸      │
│ 控制类     │                                     │  样式/绑定      │
│ 图表类     │                                     │  动作/高级      │
└────────────┴─────────────────────────────────────┴───────────────┘
```

- 工具箱宽 208–240px，使用白色面板和 1px 边框；条目为图标 + 名称，双击添加或拖拽到画布。
- 属性面板宽 264–320px，分组标题使用 `#526170` 小号文字和 1px 分隔线；输入项统一 32px 高，数值带单位和范围提示。
- 画布视口使用 `#F8FAFC`，周围留 8px 内边距；缩放范围 25%–200%，缩放比例显示在编辑工具栏。

### 4.2 网格画布背景

- 画布底色：`#F8FAFC`，不是纯白，保证白色组件仍有轮廓。
- 默认吸附网格：10×10px 逻辑网格；每 5 条细线绘制一条 1px `#C9D7E1` 主网格线，细线使用 `#E2EAF0`。
- 缩放低于 50% 时隐藏细网格，仅保留主网格，避免大画布变成噪点。
- 画布外区域使用 `#E5ECF1`，让页面边界和未使用空间清楚分离。

### 4.3 选中组件与吸附

- 单选组件：绘制 1px `#0078D4` 实线边框，外扩 2px 焦点环；四角和四边中点各一个 8×8px 逻辑手柄。手柄填充 `#FFFFFF`、边框 `#0078D4`，不遮挡组件文字。
- 多选组件：每个组件保留独立蓝色边框，外层再用 1px 虚线表示选择范围；右侧属性面板显示“已选 N 项”。
- 拖动或调整尺寸时，出现 1px `#1B9A62` 吸附参考线；参考线只在当前拖动帧存在，位于组件下方，不改变组件颜色。
- 对齐到画布边缘/中心时显示短暂的绿色端点标记；释放鼠标后立即移除参考线。
- 选中框、手柄和参考线只存在于编辑模式。复制、删除、层级和对齐操作通过工具栏/右键菜单完成，不依赖隐藏手势。

## 5. 看板运行模式

- 进入运行模式后锁定画布几何，隐藏工具箱、属性面板、网格、吸附线、选中框和缩放工具；不保留任何编辑残留框。
- 运行画布使用**纯色背景**，默认 `#EEF2F5`，也可由页面配置指定纯色。背景图若启用，必须经过裁切/拉伸规则固定，不叠加渐变遮罩。
- 顶部仅保留页面标签、连接状态、模式切换和必要的返回/停止按钮；底部仍保留采集质量、最近更新和写入反馈。
- 组件不可拖动、不可调整大小。数值显示实时值，输入组件按规范双击进入覆盖式输入框，按钮才允许触发 PLC 写入。
- 运行模式切换前若存在未保存编辑，先提示保存/继续；切换时释放所有点动按钮。运行画面中不显示“选中”视觉，组件本身的业务边框仍可存在。

## 6. 按钮五种状态

按钮的颜色是动作状态，不是页面装饰。按钮至少显示文字，必要时增加小图标；`Waiting` 不使用大面积持续闪烁，以免在报警场景造成误判。

| 状态 | 背景 | 文字 | 边框/附加表现 | 行为 |
|---|---|---|---|---|
| Normal 正常 | `#1F5A94` | `#FFFFFF` | 1px `#174A7A`；4px 圆角 | 可点击，显示动作名称 |
| Hover 悬停 | `#174A7A` | `#FFFFFF` | 1px `#103551`；鼠标为手型 | 仅在可用且鼠标悬停时出现 |
| Pressed 按下 | `#103551` | `#FFFFFF` | 1px `#0B253A`；内侧 1px 深色线 | 点击保持期间显示；点动松开后恢复 |
| Disabled 禁用 | `#DEE4E8` | `#8A96A1` | 1px `#C5CFD8`；无阴影 | 断线、只读、Bad/Disconnected 或配置无效时不可点 |
| Waiting 等待应答 | `#C4831A` | `#FFFFFF` | 1px `#925F0F`；左侧 3px 深橙条 + 旋转小图标 | 已发请求但未收到回读；禁止重复触发 |

- `Hover` 和 `Pressed` 通过明度变化而不是发光/渐变表达；按下态至少比 Normal 深一档。
- `Waiting` 的旋转指示器为 12px，动画只作用于图标；超过 3 秒的点动自动释放并显示一次错误提示。
- 按钮文字不因状态改变而换行。状态辅助文字可放在按钮下方，例如“等待 PLC 应答”。

## 7. 质量状态与连接状态

质量状态必须同时使用颜色、图标形状和文字。列表、看板数值、趋势图例和顶部连接信息使用同一语义，不为不同页面重新定义颜色。

| 质量 | 信号色 | 浅色底 | 文字/图标规则 |
|---|---|---|---|
| Good | `#1B8E53` 绿色 | `#E6F4EC` | 实心圆点 + “Good/正常”；数值保持正常文字色 |
| Stale | `#C4831A` 黄色/橙色 | `#FFF4D9` | 三角叹号 + “Stale/过期”；保留最近值并标注时间 |
| Bad | `#C73E3E` 红色 | `#FBE8E8` | 八边形/叉号 + “Bad/错误”；数值旁显示错误原因 |
| Disconnected | `#6B7280` 灰色 | `#EEF0F2` | 空心断开图标 + “Disconnected/未连接”；写控件禁用 |

- 顶部连接状态使用 8px 圆点 + 状态文字；Connecting/Reconnecting 在黄橙色上做低频闪烁（不超过 1Hz），Online 使用稳定绿色。
- Stale 不是断线：显示最后有效值和时间，不能把数值替换成 `0`。Bad/Disconnected 需要禁用写入相关按钮。
- 表格按行使用左侧色条，避免把整行染成饱和色；报警页才使用更明显的状态底色。

## 8. 趋势与报警页面

### 8.1 趋势

- 图表面板使用 `#FFFFFF`，绘图区背景 `#F8FAFC`，网格线 `#DCE5EB`，坐标文字 `#526170`。
- 默认曲线顺序：蓝 `#0078D4`、青绿 `#168A91`、橙 `#C4831A`、紫 `#7256A3`；同时显示图例、单位和质量标记。
- Stale 数据段使用同色虚线或降低不透明度，不把整条曲线改成黄色；Bad/Disconnected 以断点和图例标签表示。
- 时间范围、暂停、游标和 CSV 导出放在图表底部工具栏，避免覆盖数据区。

### 8.2 报警

- 报警表面板保持白色，当前报警行左侧使用 4px 严重度色条：Critical `#C73E3E`、Warning `#C4831A`、Info `#2B6CB0`。
- 未确认 Critical 行使用浅红底 `#FBE8E8` + 红色铃铛图标；确认后恢复白底但保留色条；恢复事件使用绿色勾号和时间。
- 报警颜色不复用按钮颜色；操作按钮仍按 Normal/Hover/Pressed/Disabled/Waiting 规则绘制。
- “当前/历史”使用明确的标签页活动线，不使用大块彩色导航卡片。

## 9. 分辨率与 DPI 验收要点

| 环境 | 布局策略 |
|---|---|
| 1366×768 | 导航 224px，顶部 44px、底部 26px；看板属性面板允许折叠，编辑器内容可滚动，标题和状态不裁切 |
| 1920×1080 | 使用默认布局；工具箱约 224px、属性面板约 288px，画布为主要视觉区域 |
| 2560×1440 | 允许工作区留白增加；导航不超过 248px，避免用超大字体填充空间，表格列可利用额外宽度 |
| 100%/125%/150%/200% DPI | 全部使用布局管理器、字体度量和逻辑像素；检查文字、图标、按钮命中区和分隔线随 DPI 一致缩放 |

验收时必须在三种目标分辨率下分别检查：顶部连接状态是否一眼可见、左侧八项导航是否完整、看板编辑器三栏是否可用、运行模式是否无网格/选中框、质量状态是否同时有颜色和文字。
