# UI-01 视觉方向提案：工业深色方案

## 1. 设计定位

工业深色方案面向长时间运行监控和夜间/低照度环境。背景采用带蓝灰倾向的深色而非纯黑，面板只提升一到两个亮度层级，保证信息分组清楚；高亮蓝色保留 Qt/Windows 生态的可识别性，绿色、黄色、红色和灰色用于质量和报警。

深色不是把浅色方案简单反相。大面积饱和色、发光边框、霓虹渐变和持续闪烁都会降低工业可读性，因此本方案只保留小面积状态色和短暂反馈。表格、趋势和看板组件均采用实色填充与清晰边界。

### 1.1 字体与密度

- 字体统一使用 **Segoe UI**；标题 18px，页面标题 14px，正文 12px，辅助信息 10px，看板数值 20px，仪表标签 11px。
- 颜色对比优先于字号放大：正文使用 `#F1F5F8`，次级信息至少使用 `#B4C0CA`，不使用低于 `#8A96A1` 的灰色承载关键状态。
- 默认控件高度 32px，主要按钮最小高度 36px，导航项 36px；逻辑尺寸由 Qt 高 DPI 布局处理，覆盖 100%/125%/150%/200%。
- 面板圆角 6px，组件圆角 4px；阴影只在浮层和弹出菜单使用 0 1px 4px `rgba(0,0,0,0.35)`，不在每个卡片上堆叠阴影。

## 2. 主色板

| 角色 | HEX | 用途 |
|---|---|---|
| 主色 `primary` | `#2E77A8` | 活动导航、主操作按钮、标题条和连接信息 |
| 主色悬停 | `#3E8FC4` | 可交互控件悬停 |
| 背景 `background` | `#111820` | 主窗口和运行画布默认底色 |
| 面板 `panel` | `#1B242D` | 导航、属性面板、表格和图表容器 |
| 面板提升层 | `#222E38` | 工具栏、表头、弹出菜单、选中行 |
| 文字 `text-primary` | `#F1F5F8` | 标题、正文、Tag 名称、数值 |
| 文字次级 | `#B4C0CA` | 单位、时间、说明和次要操作 |
| 文字禁用 | `#788691` | 禁用控件和不可用说明 |
| 边框 `border` | `#3A4854` | 面板分隔、表格线、输入框边框 |
| 边框悬停 | `#627482` | 可交互区域悬停 |
| 强调 `accent` | `#5BB9F5` | 选中框、焦点框、链接和键盘焦点 |
| 编辑参考线 | `#57D18C` | 拖拽/对齐吸附线，保持在蓝色选择色之外 |

### 2.1 工业可读性规则

- 关键正文使用 `#F1F5F8`，不使用纯白发光；深色背景与正文之间保持明显亮度差。
- 主要按钮使用 `#2E77A8` + `#FFFFFF`；在黄色/橙色等待态中改用深色文字，避免亮黄底配白字造成低对比。
- 任何低对比次级文字不能单独承载 Good/Bad/Disconnected 语义；必须有文字标签、图标或表格色条。
- 状态色只占组件小面积：圆点、左侧条、图标和必要的浅色底，不让整屏充满红/黄/绿。

┌────────────────────────────────────────────────────────────────────┐
│ ● ONLINE  PLC-01 / 192.168.1.100  [编辑模式] [保存] [设置] [?]    │  顶部状态栏 44px
├──────────────┬─────────────────────────────────────────────────────┤
│ PLC 配置     │                                                     │
│ Tag 编辑     │                    右侧工作区                       │
│ 看板         │             当前页面内容/编辑器/运行画面             │
│ 趋势         │                                                     │
│ 报警         │                                                     │
│ 历史         │                                                     │
│ 配方         │                                                     │
│ 日志         │                                                     │
├──────────────┴─────────────────────────────────────────────────────┤
│ 采集：500 ms  |  Tag：248  |  最近更新：10:32:18  |  无未保存修改   │  底部状态栏 26px

### 3.1 分区视觉

1. **顶部状态栏/工具栏**：背景 `#1B242D`，底部边框 `#3A4854`。左侧 8px 状态圆点和大写/中文状态文字优先显示，设备名称和地址使用次级文字；模式切换使用带边框的分段控件，不使用发光。
2. **左侧导航树**：宽度 224px（可在 196–280px 调整），背景 `#151E26`，右边框 `#3A4854`。活动项使用 `#243C4D` 底色、左侧 3px `#5BB9F5` 标线和 `#F1F5F8` 文字；非活动项使用 `#B4C0CA`。
3. **右侧工作区**：外层背景 `#111820`，面板背景 `#1B242D`，提升层 `#222E38`。面板边界以 1px 线表达，不依赖模糊阴影。
4. **底部状态栏**：背景 `#151E26`，文字 `#B4C0CA`，关键状态的图标使用对应状态色。错误文本显示在固定区域，避免状态更新造成页面跳动。

### 3.2 分辨率与 DPI

- 1366x768：导航保留 224px，工具箱与属性面板可折叠；不能用缩小字号来换取空间。
- 1920x1080：工具箱约 224px、属性面板约 288px，深色画布保留足够留白。
- 2560x1440：导航最多 248px，工作区可显示更多趋势列和属性分组；不把面板拉宽到信息难以扫描。
- 100%/125%/150%/200% Windows DPI：所有尺寸为 Qt 逻辑像素，使用布局管理器和字体度量；不得按截图像素硬编码坐标或图标大小。

## 4. 看板编辑模式

编辑模式仍使用深色主题，以便保持方案一致，但需要提高编辑器内部对比度。顶部模式控件选中 `编辑模式` 时显示铅笔图标和“不会写入 PLC”；运行模式写入能力只在明确切换后出现。

### 4.1 编辑器内部布局

```text
┌────────────┬─────────────────────────────────────┬───────────────┐
│ 组件工具箱 │             深色网格画布             │  属性面板      │
│ 显示类     │   可滚动、可缩放、自由摆放组件       │  位置/尺寸      │
│ 控制类     │                                     │  样式/绑定      │
│ 图表类     │                                     │  动作/高级      │
└────────────┴─────────────────────────────────────┴───────────────┘
```

- 工具箱和属性面板使用 `#1B242D`，标题分组使用 `#B4C0CA`，表单控件底色使用 `#222E38`，输入框边框 `#3A4854`。
- 画布视口底色 `#202B34`，画布外区域 `#111820`；白色或浅色组件需保留自身边框，不能直接融入背景。
- 画布缩放范围 25%–200%，工具栏显示当前缩放；编辑器的工具栏使用 `#222E38`，避免和画布背景完全合并。

### 4.2 网格、选中与吸附

- 10×10px 逻辑吸附网格；细网格线 `#2D3A45`，每 5 格的主线 `#3C4C58`。缩放低于 50% 时隐藏细线。
- 选中组件使用 1px `#5BB9F5` 实线边框 + 2px 外扩焦点环；8 个手柄为 8×8px，填充 `#E6F5FF`，边框 `#5BB9F5`。
- 多选保持每个组件的蓝色边框，外层选择范围使用 `#5BB9F5` 1px 虚线；属性面板显示“已选 N 项”。
- 拖拽、对齐和吸附参考线使用 1px `#57D18C`，必要时加 50% 透明的同色端点；不使用荧光绿填满组件。
- 参考线在释放鼠标后消失；选中框、手柄、网格和工具箱在运行模式全部移除。

## 5. 看板运行模式

- 运行画布使用纯色 `#111820`（页面可配置其他深色），不显示网格、吸附线、选中边框、手柄、属性面板和编辑工具。
- 顶部保留页面标签、连接状态、模式切换、停止/返回；工具栏背景 `#1B242D`，与运行画布形成清楚但不刺眼的层级。
- 组件锁定几何。数值组件显示实时值和质量，开关/按钮按交互状态绘制，输入组件双击后使用 `#222E38` 覆盖输入框。
- 页面切换或退出运行模式时释放点动按钮；断线、Bad 或 Disconnected 时写入按钮转为禁用态。运行画面没有任何“当前选中”装饰。

## 6. 按钮五种状态

| 状态 | 背景 | 文字 | 边框/附加表现 | 行为 |
|---|---|---|---|---|
| Normal 正常 | `#2E77A8` | `#FFFFFF` | 1px `#5BB9F5`；4px 圆角 | 可点击，显示动作名称 |
| Hover 悬停 | `#3E8FC4` | `#FFFFFF` | 1px `#8ED4FA`；鼠标为手型 | 仅可用控件响应 |
| Pressed 按下 | `#1F587C` | `#FFFFFF` | 1px `#17415C`；内侧深色线 | 点击/保持期间显示 |
| Disabled 禁用 | `#303B45` | `#788691` | 1px `#3A4854`；无悬停反馈 | 断线、只读、质量不佳或配置无效 |
| Waiting 等待应答 | `#C98A24` | `#111820` | 1px `#E0A63F`；左侧 3px 橙条 + 12px spinner | 请求未回读前禁止重复触发 |

- 深色背景上的 Waiting 使用深色文字；Normal/Hover/Pressed 使用白色文字。
- Hover 只改变背景亮度和边框，不产生外发光；Pressed 比 Normal 至少低一层明度并带轻微内边。
- Waiting 只让 spinner 旋转，按钮底色稳定；点动最大保持 3 秒，超时自动释放并在底部状态栏提示。

## 7. 质量状态与连接状态

| 质量 | 信号色 | 深色底 | 文字/图标规则 |
|---|---|---|---|
| Good | `#32C36C` 绿色 | `#193B2A` | 实心圆点 + “Good/正常”；数值文字仍为主文字色 |
| Stale | `#E5A83B` 黄色/橙色 | `#42351E` | 三角叹号 + “Stale/过期”；保留最近有效值与时间 |
| Bad | `#F05D5E` 红色 | `#452326` | 叉号/八边形 + “Bad/错误”；显示错误原因 |
| Disconnected | `#7F8B96` 灰色 | `#2A3239` | 断开图标 + “Disconnected/未连接”；写控件禁用 |

- 顶部连接指示使用 8px 圆点和文字；Online 稳定绿色，Connecting/Reconnecting 使用黄橙色低频闪烁（不超过 1Hz），Disconnected 稳定灰色。
- Stale 表示一次采集失败，不等同于断线；保留旧值但明确显示时间。Bad 和 Disconnected 不能显示为有效的绿色值。
- 关键报警同时显示图标和文字，避免只依靠深色背景上的颜色差异。

## 8. 趋势与报警页面

### 8.1 趋势

- 图表容器使用 `#1B242D`，绘图区使用 `#151E26`，网格线 `#35434E`，坐标文字 `#B4C0CA`。
- 曲线使用蓝 `#5BB9F5`、青绿 `#45C3B0`、橙 `#E0A63F`、紫 `#A98BE5`；线宽 2px，避免 1px 线在高 DPI/缩放下消失。
- Stale 区段使用同色虚线或 50% 不透明度，Bad/Disconnected 断线并在图例旁显示状态；不把全图涂成红色。
- 游标、时间范围和导出操作放在容器底部工具栏，工具栏底色 `#222E38`，不遮挡曲线。

### 8.2 报警

- 当前报警表使用 `#1B242D`，未确认 Critical 行使用左侧 4px `#F05D5E` 和 `#452326` 浅红底；Warning 使用 `#E5A83B`/`#42351E`；Info 使用 `#5BB9F5`/`#1C3445`。
- 确认后的报警回到面板底色，但保留严重度色条和确认图标；恢复事件用 `#32C36C` 勾号 + 时间。
- “当前/历史”标签页通过 `#5BB9F5` 活动线表达，不使用发光卡片。报警按钮仍遵循五种按钮状态。

## 9. 分辨率与工业可读性验收

在 1366x768、1920x1080、2560x1440 和 100%/125%/150%/200% DPI 下检查：

1. 深色面板之间至少有边框或亮度差，不能合并为一块黑色区域。
2. 正文、数值、状态文字在最暗背景上仍清楚；不能用 `#666666` 作为关键文字。
3. 顶部连接状态、左侧八项导航、看板编辑器三栏和底部更新时间都不被裁切。
4. 运行模式没有网格和选中框，编辑模式的选中框、8 个手柄和绿色参考线可见但不遮挡组件。
5. 红/黄/绿/灰状态同时有文字或图标，夜间监控时不依赖颜色猜测。
