# UI-06 Luna Dashboard 组件规格

> 本文定义看板编辑器和运行画布中 Dashboard 组件的几何边界、属性面板、编辑/运行视觉差异以及绘制规则，供 Qt Widgets 实现和视觉验收使用。
>
> 依赖文档：
> - `docs/design/design-tokens.md`：颜色、字体、间距、圆角和模式覆盖。
> - `docs/design/interaction-states.md`：编辑/运行边界、选择、缩放、写入和按钮状态。
> - `docs/design/information-architecture.md`：看板三栏编辑器、工具箱分类和添加行为。

## 1. 统一约定

### 1.1 坐标、尺寸和模式

- 所有尺寸均为 Qt 逻辑 px，尺寸写作 `宽 × 高`；组件坐标原点为组件左上角，画布位置由组件的 `x/y` 几何属性决定。
- 每个组件的默认尺寸用于工具箱添加和缺省配置；编辑器缩放、属性面板输入和配置加载都必须将尺寸钳制到该组件自己的最小/最大边界。
- 本文表格中的最小/最大尺寸是**组件的可绘制和持久化几何边界**，优先于通用默认值。UI-05 的 `60px × 40px` 是画布编辑交互和命中区域的通用基线：当某组件的可绘制尺寸更小，编辑器可以将不可见命中区扩展到至少 `60px × 40px`，但不能改变保存的组件宽高或视觉内容。
- 最大尺寸同样作用于属性面板和拖拽缩放；超出范围的导入配置在加载时钳制，不生成超出画布的半成品。
- 画布吸附步长为 `10px`。添加、移动、缩放和对齐遵循 UI-05 的吸附参考线及撤销规则。
- 编辑模式使用 `editor_canvas` 和网格；运行模式使用 `runtime_canvas`。模式切换不改变组件的保存几何尺寸、属性语义或布局。

### 1.2 编辑模式和运行模式的共同规则

| 项目 | 编辑模式 | 运行模式 |
|---|---|---|
| 画布 | 浅色 `editor_canvas`，显示可选网格 | 深色 `runtime_canvas`，隐藏网格 |
| 组件选择 | 支持选择、移动、缩放；选中显示 `#007AFF` 2px 轮廓和 8 个 8px 手柄 | 隐藏选择框和手柄，不可移动、缩放或选中 |
| Hover | 仅显示弱于选中框的半透明外沿提示 | 静态组件不显示编辑 Hover；可操作控件按运行态规则显示 Hover |
| 数据和写入 | 实时组件使用占位值或快照；任何预览点击、双击和拖拽都不发送 PLC 写请求 | 按组件规则显示实时 Tag 值；只有控制类组件可发起定义的写入或页面动作 |
| 属性面板/工具箱 | 左侧工具箱和右侧属性面板可见 | 工具箱、属性面板、编辑工具栏均隐藏 |
| 状态语义 | 选择、拖拽、缩放、未保存等编辑状态优先 | Good/Stale/Bad/Disconnected、Disabled、Waiting 和写入错误必须带文字、图标或提示，不能只靠颜色 |

组件自己的绘制规则不能覆盖上述模式边界。运行模式中所有组件仍保持编辑模式保存的几何位置和尺寸；实时值变化不得引起布局跳动。

### 1.3 属性面板通用字段

每个组件的属性面板在组件专属属性前，固定提供以下通用几何字段：

- `位置 X`、`位置 Y`：整数或逻辑 px 输入，按画布有效区域限制。
- `宽度`、`高度`：带组件专属最小/最大值的数值输入；输入和拖拽缩放使用相同钳制规则。
- `组件类型`和名称：只读，标题明确显示当前选中组件。

专属属性的控件类型按下表使用：

| 属性类型 | 属性面板控件和规则 |
|---|---|
| 文本 | 单行或多行文本框；空文本仍保留组件边界，并使用可读的空内容提示 |
| 颜色 | 颜色按钮/颜色选择器，同时显示 HEX 值；不能用颜色作为唯一状态语义 |
| 枚举 | 下拉框；保存枚举的稳定字符串值 |
| 字体/数值 | 带单位或说明的数值框；非法值在字段附近提示，不提交非法配置 |
| Tag | 可搜索 Tag 选择框，显示 Tag 名称和质量/读写信息；绑定失效时保留原 ID 并显示错误语义 |
| 布尔值 | 复选框或明确的“显示/隐藏”开关 |
| `ButtonAction` | 分类型动作编辑器；只显示当前动作需要的条件字段，详见 ButtonItem |

## 3. TextItem

### 3.1 几何和属性

| 项目 | 规格 |
|---|---|
| 默认尺寸 | `200 × 40` |
| 最小/最大尺寸 | `40 × 20` / `800 × 200` |
| 分类 | 显示类 |

| 属性 | 控件/约束 | 默认或回退 |
|---|---|---|
| `text` | 多行文本框；保留换行，文本超出组件边界时按文本布局规则裁切或换行，不改变组件尺寸 | 示例文本或空文本占位 |
| `fontSize` | 字体大小数值框，单位 px；使用 `fonts.family` 和 fallback | `fonts.sizes.body` |
| `color` | HEX 颜色选择器 | `colors.text.primary`；运行深色背景上使用可读的 `text.on_dark` 回退 |
| `alignment` | 下拉框：左 / 中 / 右 | 左 |

### 3.2 编辑/运行视觉差异

- 编辑模式显示配置后的文字、字号、颜色和对齐方式；Hover 时只在组件外沿显示弱半透明边框，选中时遵循统一蓝色轮廓和手柄。
- 双击选中的 TextItem 在原位置打开文本编辑覆盖层；覆盖层退出前不改变组件尺寸，编辑过程不发送 PLC 请求。
- 运行模式只显示静态文字，隐藏编辑 Hover、选中框、手柄和文本编辑光标；文字颜色和对齐保持配置值，必要时使用深色背景可读性回退。

### 3.3 绘制规则

1. 将内容矩形 inset 到组件边界内，使用 `fontSize` 创建字体，并按 `alignment` 计算水平对齐。
2. 以 `text` 为内容绘制；保留换行和行间距，内容超出边界时裁切到组件内容矩形，不绘制到相邻组件区域。
3. 空文本在编辑模式使用属性编辑提示，在运行模式保持空内容，不伪造业务值。
4. 绘制完成后由画布统一叠加编辑 Hover/选中层；运行模式不叠加编辑层。

## 4. RectItem

### 4.1 几何和属性

| 项目 | 规格 |
|---|---|
| 默认尺寸 | `150 × 100` |
| 最小/最大尺寸 | `20 × 20` / `2000 × 2000` |
| 分类 | 装饰类 |

| 属性 | 控件/约束 | 默认或回退 |
|---|---|---|
| `fillColor` | HEX 颜色选择器；颜色用于填充，不承担报警/质量唯一语义 | `colors.background.secondary` |
| `borderColor` | HEX 颜色选择器 | `colors.border.default` |
| `borderWidth` | 整数数值框，限制 `0–4` px；为 0 时不绘制边框 | `1` |
| `cornerRadius` | 整数数值框，限制 `0–12` px；不能超过短边的一半 | `corners.item_radius`，按短边再次钳制 |

### 4.2 编辑/运行视觉差异

- 编辑模式按填充、边框宽度和圆角正常预览；可拖拽缩放，选中时蓝色轮廓位于组件外侧，不替代配置边框。
- 运行模式保留相同填充、边框和圆角，隐藏编辑轮廓、手柄和 Hover。RectItem 不响应点击、拖拽或写入。

### 4.3 绘制规则

1. 对组件内容矩形应用 `cornerRadius`，使用 `fillColor` 填充。
2. `borderWidth > 0` 时以 `borderColor` 绘制居中的圆角边框；绘制区域不得因边框宽度改变保存的宽高。
3. 将圆角限制为 `min(cornerRadius, width / 2, height / 2)`，防止自交。
4. 选中框、手柄和拖拽半透明效果属于编辑器装饰层，不持久化到 RectItem 的绘制属性。

## 5. ImageItem

### 5.1 几何和属性

| 项目 | 规格 |
|---|---|
| 默认尺寸 | `200 × 150` |
| 最小/最大尺寸 | `40 × 30` / `2000 × 2000` |
| 分类 | 显示类 |

| 属性 | 控件/约束 | 默认或回退 |
|---|---|---|
| `imagePath` | 文件选择器或资源路径输入；路径不可读时保留路径并显示加载错误 | 空路径 |
| `fitMode` | 下拉框：`cover` / `contain` | `contain` |

### 5.2 编辑/运行视觉差异

- 编辑模式显示图片预览；空路径显示带“选择图片”语义的占位框，路径不可读显示错误图标/文字。组件仍可选择、移动、缩放和替换图片。
- 运行模式显示同一图片和适配方式，不显示占位编辑提示、选中框或手柄；图片组件只读，不响应 PLC 或画布操作。

### 5.3 绘制规则

1. 先将源图片解码为可绘制资源，并以组件内容矩形为目标区域。
2. `contain` 保持源图片宽高比，完整放入目标区域，剩余区域使用画布背景或透明填充；`cover` 保持宽高比并覆盖目标区域，超出部分从中心裁切。
3. 不允许因图片原始尺寸改变组件几何尺寸；图片缩放使用平滑变换。
4. 图片无法加载时绘制稳定的错误占位：边框、图片图标和“图片不可用”文字；不能显示空白区域让用户误认为图片已加载。

## 6. ValueItem

### 6.1 几何和属性

| 项目 | 规格 |
|---|---|
| 默认尺寸 | `120 × 60` |
| 最小/最大尺寸 | `60 × 30` / `400 × 200` |
| 分类 | 显示类 |

| 属性 | 控件/约束 | 默认或回退 |
|---|---|---|
| `tagId` | 可搜索 Tag 选择框；显示数据类型、单位、质量和读写信息 | 未绑定时显示未绑定语义 |
| `precision` | 整数数值框，限制 `0–4` | `1`；超出范围钳制 |
| `fontSize` | 字体大小数值框，单位 px | `fonts.sizes.value_display` |
| `prefix` | 文本框；显示在格式化值前 | 空字符串 |
| `suffix` | 文本框；显示在格式化值后 | 空字符串 |
| `showUnit` | 复选框；从 Tag 元数据读取单位 | 是 |

### 6.2 编辑/运行视觉差异

- 编辑模式显示 `prefix + 0`（按 `precision` 格式化）或 `0.00` 风格的占位值，使用 `fontSize`、前后缀和单位布局预览；没有绑定时显示未绑定提示。组件只接受选择和几何编辑。
- 运行模式显示绑定 Tag 的实时值，显示 `showUnit` 要求的单位；不显示编辑 Hover、选中框、手柄或可编辑光标。ValueItem 不响应点击，不发起写入。
- 运行值为 Stale、Bad 或 Disconnected 时保留数值上下文（若存在）并同时显示质量文字或图标；颜色只作辅助。没有有效值时显示 `--` 和 `Disconnected`/质量提示，而不是空白。

### 6.3 绘制规则

1. 按 Tag 数据类型转换工程值，使用 `precision` 进行四舍五入/固定小数位格式化。
2. 按顺序拼接 `prefix`、格式化数值、`suffix` 和（当 `showUnit` 为真时）Tag 单位，在组件内容矩形内完成布局。
3. 运行模式根据质量使用 `state.good/stale/bad/disconnected` 语义色，并附加可读质量标识；编辑模式使用占位值，不把占位值标记为真实 Good。
4. 文本过长时在组件内部裁切或缩小布局，不推动相邻组件，不改变宽高。

## 7. ValueInputItem

### 7.1 几何和属性

| 项目 | 规格 |
|---|---|
| 默认尺寸 | `120 × 60` |
| 最小/最大尺寸 | `60 × 30` / `400 × 200` |
| 分类 | 控制类 |

| 属性 | 控件/约束 | 默认或回退 |
|---|---|---|
| `tagId` | 可搜索 Tag 选择框；必须检查写权限和数据类型 | 未绑定时禁用运行输入 |
| `min` | 数值框；作为提交前的下限校验 | 未配置表示不设置下限 |
| `max` | 数值框；作为提交前的上限校验 | 未配置表示不设置上限 |
| `precision` | 整数数值框，限制 `0–4` | `1`；超出范围钳制 |
| `placeholder` | 文本框；输入为空时显示 | “请输入数值” |

`min` 和 `max` 同时配置时必须满足 `min ≤ max`；不合法配置在属性面板标红并阻止保存/写入，不自动交换用户输入。

### 7.2 编辑/运行视觉差异

- 编辑模式显示禁用的输入框预览、`placeholder` 和示例值；可选择、移动、缩放和配置，但点击、双击和键盘操作均不写 PLC。
- 运行模式显示当前确认值或 `placeholder`，不显示编辑选择框。单击只聚焦；双击在原组件边界上方打开输入覆盖层，覆盖层不改变画布布局。
- 输入覆盖层按 UI-05 支持 Enter 校验/提交、Esc 取消；提交后进入 Waiting，Waiting 期间阻止重复提交。连接断开、Tag Bad/Disconnected、只读或权限不足时显示 Disabled 和原因。

### 7.3 绘制规则

1. 绘制稳定的输入框边界、当前值/占位文本和必要的精度提示；边界使用普通 `border.default`，聚焦使用 `border.focus`。
2. 运行模式进入双击编辑时，在组件原矩形内创建覆盖层，并复制当前显示值；覆盖层的错误提示靠近输入框，不遮挡其他组件的关键状态。
3. Enter 前先执行数值解析、精度和 `min/max` 校验；非法值保留覆盖层并显示文字原因，不发送请求。
4. 成功时显示 PLC 确认值；失败时恢复最近确认值或安全 Disabled 状态，不能保留未确认的乐观值。

## 8. LedItem

### 8.1 几何和属性

| 项目 | 规格 |
|---|---|
| 默认尺寸 | `60 × 60` |
| 最小/最大尺寸 | `30 × 30` / `200 × 200` |
| 分类 | 显示类 |

| 属性 | 控件/约束 | 默认或回退 |
|---|---|---|
| `tagId` | 可搜索 Tag 选择框；预期为 Bool 或可转换为 Bool 的 Tag | 未绑定时显示未绑定语义 |
| `onColor` | HEX 颜色选择器 | `colors.state.good` |
| `offColor` | HEX 颜色选择器 | `colors.state.bad` |
| `label` | 文本框；显示在 LED 旁或下方 | 空字符串 |

### 8.2 编辑/运行视觉差异

- 编辑模式显示灰色/中性占位 LED 和配置的 `label`，不把占位状态伪装成实时 ON/OFF；选择和缩放使用统一编辑态。
- 运行模式按绑定 Tag 显示 ON 或 OFF：ON 使用 `onColor`，OFF 使用 `offColor`；Tag 为 Bad/Disconnected 或无有效值时使用 `state.disconnected` 的灰色语义并显示质量文字/图标。LED 不可点击。

### 8.3 绘制规则

1. 在内容矩形内按短边计算圆形 LED，保持圆形，不因组件非正方形而拉伸。
2. 根据 Bool 值绘制 `onColor`/`offColor`，同时绘制可读的 `ON`/`OFF` 文本或图标语义；`label` 使用次要文字放在稳定位置。
3. 质量不是 Good 时优先显示质量提示，颜色回退到 `state.disconnected`/对应状态色；不得只画一个灰色圆点。
4. 编辑模式的占位 LED 使用中性灰，并保留 label 版式，以便校验布局。

## 9. SwitchItem

### 9.1 几何和属性

| 项目 | 规格 |
|---|---|
| 默认尺寸 | `80 × 40` |
| 最小/最大尺寸 | `40 × 20` / `200 × 100` |
| 分类 | 控制类 |

| 属性 | 控件/约束 | 默认或回退 |
|---|---|---|
| `tagId` | 可搜索 Tag 选择框；必须检查写权限和质量 | 未绑定时 Disabled |
| `onValue` | 按绑定 Tag 类型编辑的值输入 | Bool `true` |
| `offValue` | 按绑定 Tag 类型编辑的值输入 | Bool `false` |
| `onColor` | HEX 颜色选择器 | `colors.state.good` 或按钮正常色 |
| `offColor` | HEX 颜色选择器 | `colors.border.default`/中性灰 |
| `label` | 文本框；显示在开关旁 | 空字符串 |

### 9.2 编辑/运行视觉差异

- 编辑模式只显示不可点击的 OFF 或中性预览与 label；拖拽、双击和点击不会发起写请求，选中时显示统一编辑轮廓和手柄。
- 运行模式显示明确的 `ON`/`OFF` 文字或等价标签。点击可用开关后立即进入 Waiting/短暂 Disabled，保持当前已确认值并阻止重复点击；成功后显示新状态。
- 连接断开、Tag 为 Bad/Disconnected、只读或权限不足时显示 Disabled 及原因，不发送写请求；写入失败恢复实际已确认状态。

### 9.3 绘制规则

1. 绘制圆角轨道和滑块，轨道颜色由当前 ON/OFF 状态的 `onColor`/`offColor` 决定；滑块位置与已确认值一致。
2. 在稳定的文字区域绘制 `ON`/`OFF`，并在有 `label` 时显示 label；状态文字不能因 Waiting 或 Hover 消失。
3. Waiting 使用等待色/等待图标或文字，不改变组件尺寸；请求未确认前不乐观地移动滑块。
4. 质量/权限不可用时叠加 Disabled 语义和原因提示，颜色只作为辅助。

| 分类 | 显示类 |

|---|---|---|
| `tagId` | 可搜索 Tag 选择框；读取数值和质量 | 未绑定时显示未绑定语义 |
| `min` | 数值框；定义进度映射下限 | `0` |
| `max` | 数值框；定义进度映射上限 | `100` |
| `barColor` | HEX 颜色选择器 | `colors.accent` 或 `state.good` |
| `backgroundColor` | HEX 颜色选择器 | `colors.background.secondary`/中性背景 |
| `showValue` | 复选框；显示格式化值或百分比文字 | 是 |

`min` 必须小于 `max`；无效范围显示配置错误，不绘制误导性的满格进度。

### 10.2 编辑/运行视觉差异

- 编辑模式显示 50% 的静态预览、背景槽和（若开启）示例值；不连接或读取 PLC，不显示实时质量动画。
- 运行模式按实时值渲染填充比例，隐藏选中框、手柄和编辑 Hover；组件只读。Stale/Bad/Disconnected 时保留当前值上下文并显示质量文字/图标。

### 10.3 绘制规则

1. 计算 `ratio = clamp((value - min) / (max - min), 0, 1)`；数值等于边界时分别显示空槽或满槽。
2. 先绘制 `backgroundColor` 槽，再按 ratio 绘制从左到右的 `barColor` 填充；圆角随尺寸缩放，但不得超过短边的一半。
3. `showValue` 为真时在稳定的文字区域绘制数值和必要的质量语义；文字不能因填充比例改变位置。
4. 编辑预览固定为约 50%，运行值更新只改变填充和文本，不改变组件几何边界。

## 11. GaugeItem

### 11.1 几何和属性

| 项目 | 规格 |
|---|---|
| 默认尺寸 | `150 × 150` |
| 最小/最大尺寸 | `80 × 80` / `400 × 400` |
| 分类 | 显示类 |

| 属性 | 控件/约束 | 默认或回退 |
|---|---|---|
| `tagId` | 可搜索 Tag 选择框；读取数值和质量 | 未绑定时显示未绑定语义 |
| `min` | 数值框；仪表映射下限 | `0` |
| `max` | 数值框；仪表映射上限 | `100` |
| `startAngle` | 角度数值框；单位度 | `-135°` |
| `spanAngle` | 角度数值框；单位度，限制为有效仪表弧段 | `270°` |
| `tickCount` | 非负整数数值框；定义主刻度数量 | 5 |
| `needleColor` | HEX 颜色选择器 | `colors.accent` |

`min` 必须小于 `max`；`spanAngle` 不能为 0，完整圆形和超过一圈的输入应被限制为可绘制范围。角度约定为以 3 点钟方向为 `0°`、顺时针为正方向；Qt 绘制 API 的角度方向由实现层转换。

### 11.2 编辑/运行视觉差异

- 编辑模式显示静态占位值 `0`（或按范围的起始值）、刻度和指针布局预览；未绑定时不显示实时 Good。组件可选择、移动、缩放和配置。
- 运行模式指针指向实时 Tag 值，保留刻度和标签；隐藏编辑轮廓、手柄和 Hover，GaugeItem 不可点击或拖动。
- Stale/Bad/Disconnected 时保留表盘和值的上下文，同时显示质量文字/图标；质量颜色不能替代指针或数字信息。

### 11.3 绘制规则

1. 在组件内容矩形的最大内接正方形内绘制表盘圆弧、刻度和必要的数值/范围标签，保持圆形不变形。
2. 计算 `ratio = clamp((value - min) / (max - min), 0, 1)`，将指针角度映射为 `startAngle + ratio × spanAngle`。
3. 以 `tickCount` 在弧段上均匀绘制刻度；刻度文本使用 `fonts.sizes.gauge_label`，避免和指针或边界重叠。
4. 用 `needleColor` 绘制指针和中心帽；缺少有效值时指针回到安全占位位置，并显示 `--`/Disconnected 语义，而不是伪造数值。

- 编辑模式显示静态曲线占位、坐标轴/网格（由 `showAxis` 控制）和 Tag/窗口摘要；占位曲线不代表真实数据，组件只接受布局与属性编辑。

### 12.3 绘制规则

2. 将当前窗口内的采样按时间排序并映射到绘图区，使用 `lineColor` 连接有效点；断点不跨越连接，避免把缺失数据画成连续正常线。
3. 运行模式以当前时间为右边界维护 `historySeconds` 秒窗口；重绘只更新曲线和刻度文本，不改变组件矩形。
4. 编辑模式使用可辨识但固定的占位曲线；运行数据加载失败、断开或无采样时，绘制空图表状态和可读原因。

## 13. ButtonItem

### 13.1 几何和属性

| 项目 | 规格 |
|---|---|
| 默认尺寸 | `120 × 40` |
| 最小/最大尺寸 | `60 × 30` / `400 × 200` |
| 分类 | 控制类 |

| 属性 | 控件/约束 | 默认或回退 |
|---|---|---|
| `tagId` | 可搜索 Tag 选择框；写入类动作必须绑定可写 Tag，页面跳转动作可为空 | 未绑定时写入动作 Disabled |
| `text` | 文本框；作为按钮主标签 | “按钮” |
| `action` (`ButtonAction`) | 分类型动作编辑器，见 13.2 | `fixedValue`，未配置参数时显示配置错误 |
| `normalBg` | HEX 颜色选择器 | `colors.button.normal_bg` |
| `hoverBg` | HEX 颜色选择器 | `colors.button.hover_bg` |
| `pressedBg` | HEX 颜色选择器 | `colors.button.pressed_bg` |
| `disabledBg` | HEX 颜色选择器 | `colors.button.disabled_bg` |
| `waitingBg` | HEX 颜色选择器 | `colors.button.waiting_bg` |
| `textColor` | HEX 颜色选择器 | `colors.button.normal_text` |
| `fontSize` | 字体大小数值框，单位 px | `fonts.sizes.body` |
| `borderRadius` | 整数数值框，按按钮短边钳制 | `corners.button_radius` |

### 13.2 `ButtonAction` 属性编辑器

`action` 的外层属性仍是一个 `ButtonAction`，面板按动作类型显示必要字段。动作类型和执行语义必须与 `src/dashboard/runtime/ButtonAction.h` 保持一致：

| 动作类型 | 条件字段 | 运行行为 |
|---|---|---|
| `Momentary`（点动） | `paramA` 按下值、`paramB` 松开值，可选 `confirmMessage` | 按下保持 Pressed，松开写回松开值；超过 3s 未收到释放事件时自动复位并提示 |
| `Toggle`（切换） | `paramA` ON 值、`paramB` OFF 值，可选 `confirmMessage` | 每次激活在 ON/OFF 值之间切换，等待确认期间禁止重复激活 |
| `FixedValue`（固定值） | `paramA` 目标值，可选 `confirmMessage` | 激活后写入固定值 |
| `InputValue`（输入值） | 可选 `confirmMessage`；输入校验由运行输入覆盖层负责 | 激活后打开输入流程，校验通过再写入绑定 Tag |
| `NavigatePage`（页面跳转） | `targetPageId`，可选 `confirmMessage` | 激活后切换到目标看板页，不发送 Tag 写请求 |

`confirmMessage` 非空时，在写入或跳转前显示确认对话框；对话框的主按钮应写出具体动作。动作参数控件按绑定 Tag 的数据类型输入，非法或缺失参数必须让按钮在运行模式进入 Disabled/配置错误语义。

### 13.3 编辑/运行视觉差异

- 编辑模式显示静态按钮预览、`text`、字号、圆角和 Normal 背景；不接受按钮 Hover、按下或释放动作，任何点击只用于选择/移动组件，不发送 PLC 写请求。选中时叠加统一蓝色轮廓和手柄。
- 运行模式隐藏编辑层，按 Normal、Hover、Pressed、Disabled、Waiting 五态绘制；按钮尺寸、文字位置和命中区域在状态切换时不跳动。
- Disabled 和 Waiting 屏蔽 Hover、Pressed 及键盘重复激活；Disabled 显示不可用原因，Waiting 显示“等待应答…”或等价文字/图标。
- 连接断开、Tag Bad/Disconnected、只读、权限不足或动作配置无效时进入 Disabled；写入失败短暂显示错误反馈后恢复真实 Normal 或 Disabled 状态。

### 13.4 绘制和状态规则

1. 绘制圆角按钮背景，使用当前模式对应的背景属性和 `borderRadius`；以 `textColor`、`fontSize` 居中绘制 `text`，文字布局不会因状态改变。
2. 状态优先级沿用 UI-05：错误/超时反馈 > Waiting > Disabled > Pressed > Hover > Normal。
3. Normal 使用 `normalBg`；Hover 使用 `hoverBg` 并将指针设为可点击；Pressed 使用 `pressedBg` 和轻微内阴影；Disabled 使用 `disabledBg` 并设为不可用指针；Waiting 使用 `waitingBg` 及不改变尺寸的脉冲或旋转图标。
4. Pressed/Waiting 期间保持动作文字或补充可读状态文字；动画关闭或系统启用减少动态效果时，使用静态“等待应答”文字/图标。
5. 点动动作按 UI-05 的按下、松开、3s 安全超时和异常中断规则执行；超时自动恢复到 Normal，并以黄色短暂提示“点动已超时，已自动复位”。
6. ButtonItem 只发出已配置的动作事件，由运行时执行器负责写入、确认、失败恢复和页面跳转；绘制层不能把 Waiting 误表示为 PLC 已接受写入。

## 14. 工具箱规格

### 14.1 布局和分类

工具箱位于编辑模式看板左侧面板，采用可折叠的垂直列表。分类、顺序和组件如下：

```text
显示类
  TextItem          文本
  ImageItem         图片
  ValueItem         数值
  LedItem            LED
  ProgressBarItem   进度条
  GaugeItem         仪表

控制类
  ValueInputItem    数值输入
  SwitchItem        开关
  ButtonItem        按钮

图表类
  TrendItem         趋势小窗

装饰类
  RectItem          矩形
```

- 每个条目包含语义图标、组件名称和可选的一行简短说明；图标使用固定图标槽位，不能只用颜色区分类别或状态。
- 分类标题可折叠，但四个分类名称和归属保持稳定；运行模式完全隐藏工具箱。
- 条目的最小可操作命中区遵循 UI-05 和 DPI 缩放要求；文字在 100%/125%/150%/200% DPI 下不被裁切。

### 14.2 添加行为

- **拖拽添加**：从条目拖到画布，释放时按 `10px` 网格吸附；显示绿色虚线参考线时仅表达几何辅助。创建成功后自动选中新组件并激活属性面板。
- **双击添加**：双击条目后，在当前画布可视区域的中心位置创建一个该组件的默认尺寸实例；若视口没有滚动上下文，则使用画布中心。添加后自动选中新组件。
- 拖拽和双击都不触发任何实时 Tag 读取以外的控制动作；编辑模式下绝不发送 PLC 写请求。
- 画布空间不足或配置创建失败时不创建半成品，保留工具箱选择并显示文字提示。
- 新组件的默认属性由本文件各组件章节规定；属性面板允许用户立即修改位置、尺寸、外观、绑定和动作。

## 15. 实现和验收要点

- 组件尺寸钳制必须按组件类型实现，不能用一个固定的全局最小值替代本文件的最小/最大尺寸表；编辑器不可见命中区与可绘制边界分开处理。
- 所有运行写入组件都必须经过 Tag 质量、连接状态、权限和 Waiting 防重复检查；编辑模式事件不能到达写入执行器。
- 所有质量、错误、Disabled、Waiting 和无数据状态都同时提供文字、图标或工具提示；颜色只作辅助。
- 组件绘制不得改变组件实际几何边界；文字、单位、质量提示、Waiting 图标和趋势更新都不能推动相邻组件。
- 运行模式必须隐藏工具箱、属性面板、网格、参考线、选中框和缩放手柄；组件仍使用编辑模式保存的位置和尺寸。
- 视觉验收覆盖 `1366 × 768`、`1920 × 1080`、`2560 × 1440` 以及 100%/125%/150%/200% Windows DPI。
